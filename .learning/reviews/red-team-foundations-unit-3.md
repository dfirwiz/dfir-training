## 정확성 검토

- PE32+와 CPU 종류 분리, 실제 적재 기준 주소와 선호 주소 분리, 인증서 디렉터리 파일 오프셋 예외 반영.
- 파일에 없는 0 채움 구간을 계산식으로 잘못 읽지 않도록 설명.
- OpenProcess 실패 NULL, CreateProcessW의 가장 토큰 비사용, 예약·커밋·RAM 상주의 구별 반영.
- AdjustTokenPrivileges의 ERROR_NOT_ALL_ASSIGNED와 없는 특권 추가 불가 설명.
- 일반 사용자 모드 APC의 등록과 실행, alertable wait, 시작 전 등록 문맥 구별.
- 전체 이미지 교체와 일부 덮어쓰기, 고정 PEB 오프셋의 제약 구별.
- 현재 공식 T1055 분류 확인일 명시. 단일 Sysmon 이벤트를 완전한 검출·차단으로 표현하지 않음.
- Windows ANSI는 항상 UTF-8이 아님. LONG·DWORD·BOOL·포인터 크기와 문자열 코드 단위 구별.
- 비공개 파일·식별자·화면·원문은 공개하지 않음. 공개 이름은 기존 과정명 유지.

## 검증

- stdlib 빌드 성공. 5~8강 각 11절·8복습·2그림 확인. 원문 Markdown과 HTML의 코드·표·링크 변환 확인.
- 기존 1~4강 main section을 이전 커밋과 직렬화 비교: 동일. 홈페이지 과정 카드 밖 내용 동일.
- 로컬 링크·앵커와 전체 SVG XML 파싱 통과.
- Python 합성 데이터 실제 실행: RVA 0x1120 → raw-backed/file offset 0x320, RVA 0x1350 → zero-filled/null.
- 추가 분류: 헤더 영역·미매핑 영역 확인. 잘린 파일·MZ 누락·PE 서명 오류·잘린 섹션 표 4개 오류 처리 확인.
- Windows API와 C# 예제는 컴파일·실행하지 않음. 본문에 이를 명시함.
- 브라우저 데스크톱 본문·목차·다이어그램 및 390px iframe 4개에서 본문 폭 검증: 각 document clientWidth=scrollWidth=375. 표는 343px 영역 안에서 580px 내용 스크롤. 그림은 원래 700px 폭 유지, 내부 overflow auto.
- 그림은 지연 로딩되므로 스크롤 전 미로드 상태와 실제 보이는 상태를 구분해 확인함.
