# 넷째 날 학습 범위 점검 · 2026-11-25

교재 학습 범위는 인쇄 4–152쪽이다. PDF 155쪽의 인쇄 153쪽은 연락처 안내다. 최신 목록과 회차별 검토 기록을 대상으로 범위의 연속성과 목표별 본문 연결을 확인했다. 최종 장 두 편은 원본 142–153쪽을 직접 대조했다. 이전 회차의 원문 검증 근거는 각 회차 기록을 참조한다.

| 인쇄 범위 | 강의 | 주요 학습 목표 |
|---|---|---|
| 4–37 | 1–5강 | IDS/IPS 배치, 수집·보존, TLS와 가시성 |
| 38–77 | 6–9강 | Zeek 구성, UID, 사이트 정책과 이벤트 |
| 78–122 | 10–13강 | 행위 모델·상관·기준선, 스트림 모니터링, 사용자 정의 분석기 |
| 123–141 | 14–16강 | 센서와 종단의 해석 차이, TCP 상태, 응용 필드와 경보 근거 |
| 142–149 | 17강 | 대상별 재조립과 방어 검증 |
| 150–152 | 18강 | Zeek 로그 상관과 종합 조사 |

남은 검증은 인쇄 149쪽이 가리키는 워크북·대응 실습 캡처 및 인쇄 152쪽이 가리키는 종합 실습 데이터·채점 확인이다. 연결된 자료에서 해당 원본을 확인하지 못했다. 공개 노트의 안전한 합성 문제와는 별도이며 실제 실행을 확인하지 않았다. 교재 범위의 강의는 모두 구성했지만 전체 검증 완료는 보류한다. 이후 대응 자료에 접근하면 이 기록을 갱신한다. 새로운 교재 페이지를 가정해 추가 강의를 만들지 않는다.
