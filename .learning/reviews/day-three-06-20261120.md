## 공개 검증

두 강의 콘텐츠가 포함된 커밋의 GitHub Pages 성공을 확인했다. 공개 목록, 새 두 강의와 연결을 갱신한 4강이 HTTP 200을 반환했고 생성 파일과 바이트 단위로 일치했다. HTML 254개와 내부 링크·앵커 22,714개를 검사했다. 기존 본문·메타데이터와 일차별 번호를 보존하고 이전·다음 링크를 확인했다.

공개 데스크톱과 좁은 CSS 화면을 확인했다. 문서 가로 넘침이 없고 넓은 표·도식·코드의 해당 영역 안에서 이동할 수 있음을 확인했다. 물리 모바일과 터치는 시험하지 않았다.
