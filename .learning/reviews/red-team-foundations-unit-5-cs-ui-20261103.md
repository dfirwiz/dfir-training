# 5장 Cobalt Strike 화면 실습 보강 검토 — 2026-11-03

사용자 지적: 실제 제품 화면과 어떤 설정을 해야 하는지 충분히 보이지 않음.

- 6강 제목·설명·목차 진입을 Cobalt Strike 화면 실습으로 수정. 5장 목차에 전용 바로가기, 강의 상단에 단계별 시작 카드 제공.
- 실제 화면 4개: Client 접속(기존 공개 공식 이미지 재사용), Host File(기존), Clone Site(신규), View 메뉴의 Web Log 위치(신규 공식 과거 삽화).
- 새로운 물리 PNG는 2개. 강의 19의 전체 그림 7개(개념도3+제품화면4), 5장 제품화면10개. 과정 전체 고유 PNG22개이며 Client가 4장/5장에 한 번씩 등장해 표시 횟수23회.
- Host File의 원본 선택 버튼·File/URI·Host·Port·MIME·SSL·Launch의 클릭·입력 순서와 설명값을 위치별로 대응. Client 관리 포트와 웹 포트 구별.
- Sites의 URI/Host/Port/Type/Description, Copy URL/Kill을 표로 설명. 이 표를 실제 캡처로 제시하지 않음. 공식 문서의 구형 메뉴 경로와 버전 주의 표시.
- Web Log는 실제 구형 View 메뉴 이미지. 결과 탭의 현재 화면이나 새 실행 결과로 표현하지 않음. 가상 요약은 명시적으로 구별.
- Clone Site는 원본 URL/새 URI/호스트/포트/Attack(본문Embed)/입력 기록 선택/Clone 위치 설명. 공식 과거 예시 값과 체크 상태를 그대로 따라 넣지 않도록 자체 정적 페이지·Attack 빈 칸·입력 기록 미선택으로 가정.
- 이미지 원본은 수정하지 않고 웹 표시에서 확대. 원본 링크·대체 텍스트·출처와 버전 주의 유지.
- 기존 1~18강의 본문·복습·예제는 유지. 실제 서버·연결·복제·요청은 미실행.

검증: 빌드·원본/그림 메타데이터·기존 본문 비교·모바일 폭·바로가기·배포 후 운영 응답을 확인한다.

검증 결과: 빌드와 18개 기존 본문 비교·홈페이지 과정 카드 밖 비교 통과. 이미지7개 선행 로드와 크기 예약, 이 강의만 즉시 스크롤 적용. Host File 바로가기의 제목 위치는 데스크톱30px·모바일30px. 모바일 viewport/scrollWidth 모두375px, 사진은327px 영역 안에서640px 내부 스크롤. 이미지4개 모두 정상 로딩.
