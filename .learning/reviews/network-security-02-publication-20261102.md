# 네트워크 보안 분석 2강 게시 전 검증

- 사용자의 채팅 검토본 2강 전체를 별도 원본 파일로 옮겼습니다.
- 교육 본문 253개 문단, 20개 절, 표 7개, 코드·명령·도식 블록 23개, 그림 3개, 복습 12문항과 즉시 읽는 해설을 대조했습니다.
- 코드 블록의 문자열을 원본과 대조했습니다. 실행되지 않은 TShark·Zeek 예시라는 안내를 유지했습니다.
- 공개 페이지의 변경은 강의 제목을 페이지 머리말로 배치하고 로컬 이미지 경로를 동일 내용의 SVG로 바꾸며 내부 원문 경로·쪽수 안내를 제외하는 것으로 제한했습니다.
- 공식 출처 링크와 확인일, 적용 문서 버전, 관측 한계와 가상 사례 안내를 유지했습니다.
- PC 화면과 390px 모바일 화면을 확인했습니다. 문서 전체에 가로 넘침이 없으며 넓은 표와 코드가 내부에서 스크롤됩니다.
- 강의 페이지·목차·홈의 내부 링크와 앵커를 검사했습니다.
- 1강 교육 본문은 이전 게시본과 동일합니다. 2강 이동 링크와 과정 목차만 갱신했습니다.
- 진행 정보의 완료 범위는 2강까지, 다음 범위는 DNS 동작 원리입니다.

배포 성공 여부와 공개 주소의 응답은 저장소 반영 후 별도로 확인합니다.
