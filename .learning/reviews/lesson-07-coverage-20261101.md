확인일: 2026년 11월 1일. 최신 main의 편집 기준·진행 상태·과정 목록·생성 스크립트, 상세 보강된 1·2·3강과 직전 6강의 본문을 확인했습니다. 기존 본문의 설명은 축약하지 않습니다.

## 범위 조정

기존 7강 예정 범위 57~70쪽을 개념 경계에서 나눴습니다. 이번 7강은 인쇄 57~61쪽 / PDF 59~63쪽의 통계와 조사 후보 선택입니다. 새 8강은 인쇄 62~70쪽의 TCP 스트림·객체 분석과 연습으로 예정했습니다. 이후 예정 회차 번호와 슬러그 접두어를 1씩 이동하고 stop_after_lesson_id를 16으로 조정했습니다. 이미 공개된 1~6강 URL과 본문은 유지했습니다. 범위는 마지막 167쪽까지 연속되며 이번 실행에서 한 회차만 완료합니다.

## 예제와 한계 검토

- 시간: 20분×60=1200초, 840초÷60=14분. 사건 시각 포함과 실제 수집은 다른 조건임을 설명.
- 크기: 120000-100000=20000바이트. 차이를 유실·반출로 단정하지 않음. 100000바이트/1000개=평균100바이트.
- 단위: 120000/1000=120 kB, 120000/1024=117.1875 KiB.
- 계층: Ethernet 100%, IPv4 100%, TCP 80%는 같은 패킷을 중복 집계할 수 있으므로 합계280%가 단독 오류 근거가 아님.
- 가상 대화: 6000+54000=60000바이트, B→A 비율90%. 패킷 집계와 실제 응용 파일 크기를 구분.
- A/B를 클라이언트·서버 또는 내부·외부로 자동 해석하지 않음. 포트만으로 응용을 확정하지 않음.
- 명령은 파일 열기 사용 예시이며 실행 결과가 아님. 가상 HTTPS 경로는 암호화된 패킷에서 항상 읽힌다고 가정하지 않음.

## 현재성 확인과 근거

공식 Wireshark 문서의 Capture File Properties, Protocol Hierarchy, Conversations, 시간 표시, 실행 매뉴얼과 TLS 분석 문서를 조회했습니다. 확인 날짜와 링크는 본문에 기록했습니다.

세 통계 창으로 전체에서 후보를 좁히는 원칙은 현재도 유효합니다. 탭의 부재를 데이터 부재로 단정하던 해석은 현재 Protocol 표시 선택과 프로필 설정을 확인하는 설명으로 보완했습니다. Limit to display filter와 절대·상대 시각, pcapng 메타데이터, 계층의 중복 집계와 암호화의 가시성 한계를 추가했습니다. 도구의 최신 릴리스 번호나 재현 결과는 추측하지 않습니다.

## 게시 전 확인

홈페이지와 노트 7개, 로컬 링크·자산 321개를 검사했습니다. 새 본문의 11절·참고문헌 6개, 목차·앵커·중복 ID·이전/다음 링크, 표와 SVG 접근성 제목 및 구조, 예제 계산과 진행 기록을 확인했습니다. 공개 본문과 검토 기록에 원문 전문·화면·업로드 식별자·개인정보를 넣지 않습니다.

기존 폰트·어두운 배경·민트 강조와 반응형 스타일은 유지합니다. 미리보기 인프라 제한으로 실제 브라우저의 시각 검증은 수행하지 못했습니다. 구조 검사와 시각 검증을 동일시하지 않습니다.

완료 지점은 인쇄 61쪽이며 다음 시작은 새 8강의 인쇄 62쪽입니다. 인쇄 62~70쪽은 미완료로 남겨 다음 실행에서 원문과 다시 대조합니다. 전체 학습 상태는 진행 중입니다.
