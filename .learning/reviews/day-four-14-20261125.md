# 넷째 날 14강 검토 · 2026-11-25

인쇄 123–130쪽과 대응 PDF 125–132쪽의 시그니처 탐지 절 표지, 센서·종단 해석 불일치, 체크섬과 오프로딩, ACK 해석의 한계, IP·TCP 계층의 재조립 문제를 추출 텍스트와 렌더 이미지로 직접 대조했다. 원본 공격 재현, 패킷 제작 절차, 화면과 파일은 복제하지 않고 방어적 수집·정규화·종단 검증으로 재구성했다.

2026-11-25 현재 RFC 9293에서 TCP 체크섬·순서 번호·누적 ACK를, Wireshark 공식 안내서에서 체크섬 검증·오프로딩·부분 체크섬과 재조립을, Suricata 8과 Snort 3 공식 문서에서 스트림 재조립·정규화·운영체제 정책·자원 한도를 확인했다. 원문의 공격 절차는 옮기지 않고 탐지 누락을 줄이는 설정 검증과 증거 결합만 설명했다.

이번 실행에서는 원본 해당 페이지의 텍스트와 렌더 이미지를 직접 확인했다. 실제 캡처, 워크북, 센서, 서버, 명령 실행과 외부 시스템 시험은 수행하지 않았다. 정적 검사와 공개 화면 검증은 게시 단계에서 별도로 기록한다.
