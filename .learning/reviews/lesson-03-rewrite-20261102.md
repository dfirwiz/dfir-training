## 이번 직접 자료 대조

본 교재 인쇄 22~30쪽(PDF 24~32쪽)을 다시 확보했습니다. 해당 범위의 PDF 추출 텍스트가 0자임을 확인하고 Tesseract 영어 OCR을 새로 실행했습니다. 페이지 이미지 전체의 도식·표제·범위와 기존 고해상도 OCR을 함께 대조했습니다. 저해상도 새 OCR이 VLAN/VXLAN, 포트, 길이 숫자를 잘못 읽은 부분은 페이지 도식 및 표준·기존 OCR로 확인했습니다. 원문·화면·OCR 전문과 실습 입력은 커밋에 넣지 않습니다.

기존 워크북 검토 기록의 계층 개념·tcpdump·이름 변환·필드 기준점 학습 목표를 연결했습니다. 이전 여섯 PCAP/621기록 오프라인 검증은 기존 검토이며 이번 실행에서 원본 PCAP·워크북을 다시 분석하거나 tcpdump/TShark/GUI를 실행한 것은 아닙니다. 전용 VM·네트워크 장비 동작은 재현하지 않았습니다.
