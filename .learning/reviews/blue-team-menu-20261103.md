# 블루팀 필수 지식 과정 메뉴 개편

- 요청: 과정명을 블루팀 필수 지식에 맞게 변경하고 첫째 날부터 날짜별 하위 강의 목차 구성. 이번 작업은 메뉴 개편에 한정.
- 공개 제목: 블루팀 필수 지식: 보안 운영과 분석.
- 범위 확인: 로컬 교재 1~5권의 과정 개요와 목차를 읽어 날짜별 대주제와 준비 중 학습 범위를 정함. 교재 원문·화면·PDF를 공개하지 않음.
- 구성: 첫째 날 보안 운영 기초, 둘째 날 네트워크, 셋째 날 단말·로그·파일, 넷째 날 경보 분류·조사, 다섯째 날 탐지 개선·자동화, 여섯째 날 독립 종합 실습 계획. 여섯째 날의 실제 실습 파일 제공·실행을 의미하지 않음.
- 기존 공개 6편: URL과 강의 본문을 보존하고 둘째 날 1~6강으로 메뉴에 배치. 다음 집필은 첫째 날 1강으로 변경.
- 데이터: `course.json`의 `lessons`에 강의 원본 정보, `days[].lesson_ids`에 묶음 순서. 준비 중 항목에 가짜 링크를 생성하지 않음. 상세 집필 때 회차를 더 세분화할 수 있음을 안내.
- UI: 홈페이지 과정 카드, 과정 소개, 7개 과정 페이지의 날짜별 접기·펼치기 목차, 현재 강의 표시, 같은 날 앞뒤 이동. 모바일에서는 날짜 메뉴 내부 스크롤 및 강의 상태 줄바꿈.
- 검사 완료: 8개 HTML 문서 구조·중복 ID·상대 경로·내부 앵커, 날짜 그룹 6개, 기존 6편의 본문 완전 일치, 홈페이지의 이 과정 카드 바깥 내용 보존.
- 화면 검사 한계: 컴퓨터 사용 도구 초기화가 커널 경로 오류로 실패하여 실제 브라우저와 모바일 렌더링은 확인하지 못함. 브라우저 검사를 수행한 것으로 보고하지 않음.
- 다른 작업 보호: 원래 체크아웃의 관련 없는 CSS 미완료 수정을 건드리지 않고 최신 원격 커밋에서 별도 체크아웃으로 작성함.
