## 정확성 검토

- Client 접속과 Beacon 수명, 서버별 세션 출처, 통신 형식과 실행 포장 구별.
- HTTP GET/POST는 기본값이며 고정 탐지 조건으로 일반화하지 않음. 프로파일 variant와 메타데이터 배치 의미 설명.
- C2/Bind 포트, DNS/SNI/Host/인증서, 프록시/훈련 중계 관측 위치 구별.
- random 반복 선택 가능, 연속 실패와 성공 초기화·sleep/jitter 구별. 현행 문서와 이력의 도입 버전 불일치는 최초 도입일을 확정하지 않음.
- DNS 재귀·권한·위임, TLD 오해, 레코드 유형과 전송 IP 계층, DoH와 센서 범위 구별.
- stager의 프록시·resolver·Guardrails 적용 차이, 초기 staging과 후속 C2 보안 경계 구별.
- 로컬 파이프와 원격 445, Beacon 부모와 프로세스 부모, 대기 주소와 실제 도달성 구별.
- 링크 해제와 프로세스 종료, 생성·보관·전달·실행·완료·정리 상태를 구분.
- 4.11 prepend 로더, 4.12 작업 ID, 4.13 상태 추적·Payload Store를 공식 이력과 대조.
- syscall 선택 표기와 실제 호출 경로·탐지 효과를 구별. 실행·회피 성공을 주장하지 않음.
- 외부 주소 출처, PID 재사용·arch/OS·high integrity/SYSTEM·last/sleep·시간 기준의 차이를 설명.

- stdlib 빌드 성공. 5강 총 55절·18표·10그림·40복습 및 해설 생성 확인.
- 기존 1~8강 main section을 이전 커밋과 직렬화 비교: 모두 동일. 기존 날짜 2026-11-02 유지, 새 9~13강은 2026-11-03.
- 홈페이지의 해당 과정 카드 밖 내용은 동일. 로컬 링크·앵커와 SVG XML 파싱 통과.

- 13강 코드 직접 실행 출력: T01 completed 5s / T02 completed 2s / T03 canceled -.
- 실습은 합성 이벤트의 단순 상태 모델이며 실제 제품 로그 파서·단말 실행·C2 통신을 검증한 것이 아님.
