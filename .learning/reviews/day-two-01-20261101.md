# 둘째 날 첫 강의 검토

확인일: 2026년 11월 1일. 공개 노트 23, 둘째 날 1강. 학습 범위는 인쇄 4~11쪽에 대응하는 표시 필터의 기본 개념입니다. 다음 범위는 인쇄 12쪽부터입니다.

## 본문과 시각 자료

채팅 검토본의 설명 순서·문단·사진첩과 택배 송장 비유·주소 및 DNS 예제·Find Packet 비교·버전 차이·가상 조사·복습 4문답을 유지했습니다. 공개 과정 명칭에 맞춰 제목을 조정하고 보충 설명을 추가했습니다. 원문 PDF, 교재 화면, OCR, 원본 실습의 답을 저장소에 추가하지 않았습니다.

- 다이어그램 4개: 캡처와 표시 단계, 바이트에서 DNS 필드로의 해석, 요청·응답의 질의 이름, 조사 범위의 축소와 확대.
- 비교 표 8개: 필터 종류, 필터 세 요소, 방향, 비교 연산자, 문자열 패턴, 문맥 조사, 제외 범위, 결과 없음의 원인.
- 복습 8문답: 채팅의 기존 4문답과 버전·대소문자·암호화·도구 보안의 추가 4문답. 답변은 접지 않고 바로 표시합니다.

## 현재 지침 보충

Wireshark 공식 사용자 안내서와 DNS 필드 참조로 문법을 확인했습니다. `!=`는 3.6부터 의미가 바뀌었음을 명시했습니다. 현재 산술 연산 지원, `contains`와 `matches`의 대소문자 차이, `lower()`와 참·거짓 필드의 존재·값 구별도 반영했습니다.

RFC 8484와 Wireshark TLS 안내로 암호화된 DNS에서 질의 이름이 보이지 않을 수 있는 조건을 설명했습니다. 443번 포트만으로 DoH를 판정하지 않고 수집 범위와 단말·리졸버 자료를 대조합니다.

2026-08-12 발표된 `wnpa-sec-2026-84`와 2026-09-23 발표된 `wnpa-sec-2026-106`을 각각 PCAPNG 파일 해석과 설정 프로파일 가져오기로 구별했습니다. 각 수정 버전과 확인일을 표기하고, 영구적인 최신 버전이라는 표현을 피했습니다. 보안 권고와 공식 근거 링크는 공개 본문에 포함됩니다.

## 검증과 한계

HTML 태그 균형·ID 중복·로컬 링크 및 앵커·카탈로그를 검사했습니다. 기존 22개 강의의 본문이 변경되지 않았음을 저장소 버전과 대조했습니다. 공통 목차와 첫 화면에 둘째 날 구분을 추가했습니다. 첫째 날 완료 기록과 자동화 상태는 변경하지 않았습니다.

브라우저 도구가 `failed to write kernel assets: The system cannot find the path specified`로 시작하지 못했고 초기화 후 재시도도 실패했습니다. 따라서 데스크톱·모바일 브라우저 시각 검증은 수행하지 못했습니다. 가로로 긴 표·그림·코드는 기존의 내부 가로 스크롤 스타일을 사용합니다. 예제는 공식 문서와 대조했으며 Wireshark·TShark 실제 실행 검증으로 표시하지 않습니다.
