# 첫째 날 1강 승인본 게시 검토

2026년 11월 1일. 사용자가 채팅에서 검토하고 그대로 게시하도록 지시한 1강을 반영합니다. 범위는 기존 인쇄 4~11쪽과 기존 현대적 보충이며 과정명·URL·번호와 다른 강의는 유지합니다.

## 승인본 보존

- 범위·자료 확인 안내와 11개 절의 순서, 모든 문단·비유·예시·목록·표·복습 해설을 유지했습니다.
- 승인본의 제목·문단·목록 항목·표 셀 314개 텍스트 단위가 HTML에 그대로 존재함을 대조했습니다. 서식 기호와 인용 표시의 웹 형식 변환만 적용합니다.
- 표 10개, 복습 문답 10개, 즉시 읽는 해설 10개를 보존했습니다.
- Mermaid의 7개 노드·7개 간선과 예/아니요 분기 및 관련 패킷 재검토로 돌아가는 관계를 접근 가능한 SVG로 옮겼습니다. 모바일에서는 내부 가로 스크롤로 글자 크기를 유지합니다.
- 채팅 출처 표시는 같은 공식 문서의 본문 참조 링크 7개로 변환했습니다. 교재 PDF나 화면 및 개인 경로는 게시하지 않습니다.

## 범위 대조

학습 자료 역할과 변경 사항 확인, 전체 학습 흐름, 기초 지식·반복·종합 실습의 이유, 패킷·헤더·페이로드·계층 경계, IDS/IPS와 오탐·미탐, 네 가지 공격 경고 결과, 규칙·전후 통신·관측 위치·다른 로그 대조, 우선순위와 공격자 추정의 한계, 도구 검증, 관측·가설·결론을 모두 포함합니다. TLS 1.3·QUIC·ECH·암호화된 통신의 분석 가치와 Zeek·단말·서버·클라우드 기록의 연결도 유지했습니다. 워크북 연계 실습 가이드 링크를 보존했습니다.

## 검증

- 승인본의 텍스트 보존 검사, HTML 구조·중복 ID·내부 파일·앵커 검사와 SVG XML 검사를 수행합니다.
- 최신 main의 본문·생성기·목차를 기준으로 첫 페이지와 목록을 갱신합니다. 다른 회차의 본문과 기존 진도 상태는 덮어쓰지 않습니다.
- 로컬 브라우저 미리보기는 preview relay unavailable 환경 오류로 실행되지 않았습니다. 배포 후 브라우저 점검 결과는 실제 수행 여부에 따라 별도로 기록합니다.
- 워크북·PCAP 기존 검증 기록과 이번 직접 검증을 구분합니다. 이번 게시 작업에서 원본 실습을 재실행했다고 주장하지 않습니다.
- 다음 개정 대상은 첫째 날 2강입니다. 자동 연재를 활성화하지 않습니다.

게시 완료 여부는 GitHub Pages의 해당 커밋 배포 결과로 확인합니다.
