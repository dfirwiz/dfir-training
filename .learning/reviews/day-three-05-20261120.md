# 셋째 날 5강 교재 대조와 실습 검증 · 2026-11-20

인쇄 51~65쪽(PDF 53~67쪽)의 내장 텍스트와 그림·표·화면을 대조했다. 별도 원본 PCAP·워크북의 파일과 문항은 확인하지 못했다. 공개 예시는 독립적인 교육용 정상 패킷과 가상 경보를 사용한다.

| 교재 범위 | 학습 목표 | 본문 절·검증 |
| --- | --- | --- |
| 51~52쪽 | 시그니처 탐지 도입, 패킷 입력·해석·탐지·출력 | `pipeline`. 처리 순서의 독립 도식, 수동·인라인 관측 차이 |
| 53~56쪽 | 분석가의 검증, 규칙·정책 조정, 공개 권고의 방어적 사용 | `goal`, `configuration`, `alerts`. 분류와 침해 판정을 구별하고 입력과 규칙 개정 기록 |
| 57~58쪽 | Suricata와 Snort 비교, 여러 호스트·시각의 상관과 가시성 제한 | `inspectors`. 역사적 버전 단정을 피하고 EVE와 Snort 로거 구분 |

| 64~65쪽 | 파일로 읽기, 설정·규칙 로드와 경보 출력, 워크북 안내 | `offline`, `alerts`, `review`. 공식 옵션 문법, 가상 두 행의 파싱과 집계. 별도 문항 미확인 |

공개 가상 JSON 두 행을 파싱해 서로 다른 패킷 번호, 고유 규칙 개정 한 개, 방향별 주소·포트 한 쌍을 검산했다. Snort·Suricata 실행이나 실제 센서 경보는 재현하지 않았다. 2026-11-20에 Snort 3 제작사 문서와 Suricata EVE 자료를 조회했다.
