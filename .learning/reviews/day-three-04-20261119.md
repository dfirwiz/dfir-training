# 셋째 날 4강 교재 대조와 실습 검증 · 2026-11-19

셋째 날 교재의 인쇄 36~50쪽(PDF 38~52쪽) 내장 텍스트와 그림·표·화면을 직접 대조했다. 사례의 실제 주소·파일명·표본·사업 정보를 재게시하지 않고, 정상 진단 문자열을 이용한 독립 조사 장부로 같은 판단 목표를 풀었다. 원본 캡처와 별도 워크북은 확인하지 못했다.

| 교재 범위 | 학습 목표 | 본문 절·검증 |
| --- | --- | --- |
| 36~38쪽 | 신고를 구체화하고 통계·대화·원인 가설을 추적, 타임스탬프의 출처 비교 | `goal`, `pivot-map`. 센서 시각·내용의 시각·보정값을 구분 |
| 39~40쪽 | 프로토콜 계층, TCP 대화·방향별 양, 대화 따라가기 | `statistics`, `pivot-map`. 예제 17,200바이트 차이와 대화·응용 본문의 개별 의미 |
| 41~42쪽 | 요청 본문을 확인하고 이전 HTTP 활동으로 이동 | `pivot-map`, `before`, `timeline`. 가상 POST 20바이트와 HTTP 200 관측의 한계 |
| 43~44쪽 | 표시 유형·실제 본문·스크립트 단서, 파일과 단말 행위의 증거 구분 | `before`, `report`. 바이트·형식·수용·실행을 검토하고 코드 실행이나 원 사건을 재현하지 않음 |
| 45~47쪽 | DNS 답변에서 이름, 메일에서 가설, 두 번째 단말과 수신자 범위 | `dns-mail`, `timeline`. 안전한 문서용 주소와 도메인, 로그 상관 및 DNS 미관측의 한계 |
| 48~50쪽 | CLI 표시 필터와 필드, 분석 절차 복습과 별도 워크북 | `tshark`, `review`, `references`. 원래 프레임 재확인, 평문·범위·도구 한계. 별도 워크북은 미확인 |

가상 장부 여섯 행의 시각 정렬, 5·51·1초 간격, 요청 본문 20바이트와 방향 집계 차이를 검산했다. Wireshark GUI·TShark 필터 엔진과 실제 서버 데이터는 검증하지 않았다. 2026-11-19에 Wireshark 제작사 자료와 HTTP·TLS 규격을 확인했다.
