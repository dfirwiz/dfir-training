# 셋째 날 2강 교재 대조와 실습 검증 · 2026-11-19

셋째 날 교재를 다시 확보했다. 인쇄 14~25쪽에 해당하는 PDF 16~27쪽의 내장 텍스트와 그림·표·화면을 대조했다. 제목 검색에서 셋째 날의 별도 워크북 및 원본 캡처를 확보하지 못했다. 기존 첫째·둘째 날 검토와 셋째 날의 별도 자료 상태는 구분한다.

| 교재 범위 | 학습 목표 | 본문과 확인 |
| --- | --- | --- |
| 14쪽 | 캡처로부터 필요한 표본 선택 | `goal`, `evidence-copy`. 원본, 작업 사본과 검산용 변형을 구분 |
| 15~16쪽 | 저장된 계층과 데이터 읽기, 복사·수정 후 길이 및 체크섬 갱신 | `dependencies`, `rebuild`, `exercise`, `results`. 같은 길이와 다른 길이의 정상 UDP 표본 비교, 명시적 0과 자동 계산 |
| 17~20쪽 | 파일 작업과 네트워크 관측의 차이, 커널·종단 상태와 센서 응답 해석 | `live-capture`. RST·ICMP·정책의 해석과 오프로딩. 직접 송신 또는 응답 차단 재현은 범위 밖 |
| 21쪽 | 대화형 탐색과 반복 스크립트 | `automation`, `exercise`. 파일 입력·기대값·결과 기록을 반복 가능하게 설계 |
| 22~23쪽 | TCP 윈도와 지연 관측 | `window`. 방향별 윈도, 일시적 수신 지연, 정책 가설과 추가 증거. 구현이 아닌 캡처 해석 범위 |
| 24쪽 | 도구 선택과 자동 필드 계산 | `automation`, `rebuild`. 탐색과 반복 점검을 구별하고 자동값을 파일의 바이트에서 확인 |
| 25쪽 | 별도 워크북 실습 연결 | `review`, `automation`. 독립 실습과 해설 6개. 별도 원본 문항·기재 결과는 미확인 |

Scapy 2.5.0으로 1강 코드에서 생성한 가상 입력을 읽고 본문 코드를 실행했다. 원본 해시가 그대로이며 출력의 두 레코드를 다시 읽었다. 독립 파서로 오프셋, IP·UDP 길이, IPv4 및 UDP 체크섬을 검사했다. 메모리에 남아 있는 원래 프레임 길이까지 확인해 가상 출력에서는 48/50바이트에 맞게 메타데이터를 갱신했다. 기존 파일을 덮어쓰려는 두 번째 실행은 새 파일 전용 열기에서 중단됨을 확인했다. 네트워크 전송, 현장 수집, Snort·Suricata 경보는 검증하지 않았다.
