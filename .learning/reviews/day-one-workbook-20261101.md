# 첫째 날 워크북과 PCAP 보충 검토

2026년 11월 1일. 기존 교재 해설 21강과 인쇄 4~167쪽 범위를 유지하고 워크북의 여섯 학습 주제를 연결한 보충 22강을 추가했습니다. 원본 전자 워크북의 README 표시 갱신일은 2021년 7월 26일입니다. 이 날짜를 최신 강의 판본의 확정 근거로 사용하지 않습니다.

## 반영 범위

| 워크북 주제 | 기존 강의 연결 | 추가 설명 |
| --- | --- | --- |
| 계층 개념과 tcpdump | 3~5강, 18강 | 이름 변환, 계층별 식별값, 기준점과 길이 |
| Wireshark 탐색 | 6~8강 | 계층 통계, 대화 단위, 헤더 끝, 스트림과 문자열, TCP 옵션 |
| 링크 계층 | 9~11강 | ARP 요청·응답, 충돌 대응, 학습 자원, 자발적 ARP |
| IPv4 | 12~13강 | 버전, IHL, 주소 바이트, 길이, 체크섬과 관측 조건 |
| 단편화 | 14~17강 | 처음·마지막 조각, 옵션 복사, 구간표, 필터와 중첩 |
| IPv6 | 22강 | 기본 헤더, RS·RA와 NS·NA, 확장 헤더, 조각, 주소 대응 |

기존 18개 강의에 관련 실습으로 가는 링크를 추가했습니다. 기존 표·SVG·명령 예시는 보존했습니다. 워크북 미제공 안내와 첫째 날 PCAP 미제공 안내는 현재 상태로 수정했습니다. HTTP 사례·전용 패킷 회수 도구처럼 여섯 파일과 별개의 입력에 관한 한계는 유지합니다. 기존 자체 예시를 실제 PCAP 실행 출력으로 바꾸어 표시하지 않습니다.

## 파일 대조와 분석

추가 제공된 첫째 날 캡처 여섯 개, 총 621개 기록을 오프라인으로 해석했습니다. 실제 형식은 PCAPNG 네 개와 PCAP 두 개였습니다. 파일 헤더·블록 길이·시각·Ethernet·ARP·IPv4·TCP·IPv6 필드를 별도로 읽고 dpkt 1.9.8과 모든 기록을 교차 검증했습니다. DNS 질의·응답과 전체 ICMP 응답 체크섬도 확인했습니다. 저장된 captured length가 original length보다 작은 기록은 없었습니다. 당시 회선의 손실 여부까지 판정한 것은 아닙니다.

워크북의 주요 주소·번호·문자열·필드는 실제 입력과 대응합니다. 화면에 반올림된 대화 바이트와 시간은 원래 정밀도 계산과 구분했습니다. 일부 기재 조각 플래그와 실제 바이트의 차이, IPv6의 두 조각 사이 빈 구간도 개인 학습 가이드에 기록했습니다. 실제 원본 스트림·PCAP·워크북·개인 학습 가이드는 공개 저장소에 포함하지 않습니다. 공개 22강은 문서용 주소와 독립 예시로 원리를 설명합니다.

## 설명 보완

같은 IP와 MAC의 관계, CAM 자원 고갈 뒤 전달, 재조립 타이머, 조각 크기의 다양성, 값 0의 체크섬, RS와 주소 해석, IPv6 확장 헤더 처리 범위를 조건과 함께 설명했습니다. IPv6 중첩 조각은 IPv4 중첩 처리 관측과 분리했습니다. tcpdump·libpcap 공식 매뉴얼, Wireshark 가이드, IPv4·호스트 재조립·IPv6·이웃 탐색·IPv6 중첩 표준을 확인했습니다.

## 검증과 한계

- 정적 페이지 생성, 전체 HTML 구조·로컬 파일·앵커와 진행 정보의 일관성을 검사합니다.
- 기존 표·도식·명령 보존과 길이·MSS·체크섬·조각 구간 계산을 검산합니다.
- 새 가이드의 데스크톱·모바일 레이아웃과 로컬 개인 가이드를 브라우저에서 확인합니다.
- 오프라인 해석은 tcpdump·TShark 명령 또는 Wireshark GUI를 직접 실행한 기록이 아닙니다. 전용 VM·스위치·라우터·피해 OS의 반응·강의 음성 답안은 재현하지 않았습니다.
- 기존 모든 회차의 화면을 다시 시각 검사한 것은 아닙니다. 기존 연재 자동화는 다시 켜지 않습니다.
