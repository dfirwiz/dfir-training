## 워크북 범위와 다음 회차로 남긴 항목

전자 워크북 BPF 실습(2.2)의 전체 문제·힌트·기재 해설을 확인했다. 이번 회차의 상세 풀이 대상은 준비와 문제1·2다. 준비의 숫자 출력/시각 생략 옵션, 플래그 위치와 검증 절차를 command, flags, lab에서 설명했다. 문제1은 정확 SYN의 목적지 포트, 문제2는 정확 SYN/ACK의 출발지 포트와 고유값·중복 의미로 연결했다.

문제3(FIN 또는 RST), 문제4(목적지143·PSH/ACK 포함·처음5개), DNS QR/ARCOUNT 추가 문제 및 주소 끝 바이트 마스크 추가 문제는 다음 노트26의 범위로 명시했다. 읽었다는 사실을 모든 풀이·실행 완료로 기록하지 않는다. 표본 수가 많다는 이유로 모든 질문을 검증했다고 주장하지 않는다.

## 수정한 원문 설명과 현재 지침

- 일반 태그 없는 Ethernet II의 EtherType은 오프셋12~13이며 14는 그 뒤 IP 시작점이다. 해당 원문 위치 설명의 혼동을 바로잡았다.
- `tcp` 프로토콜 조건과 `ip[9]=6`, 전송 계층 데이터 접근자의 IPv6 구현 범위를 구별했다. 링크 유형·VLAN·확장 헤더를 무제한 처리한다고 가정하지 않았다.
- BPF 비교 `=`와 `==`가 모두 지원됨을 설명했다.
- Windows 전체가 아니라 셸(Bash/PowerShell/cmd)에 따라 따옴표 처리 맥락을 구별했다.
- AND/OR의 같은 우선순위와 왼쪽 결합, 비트`&`와 조건`and`, unsigned 비교의 의미를 공식 문서와 대조했다.
- IHL 마스크가 정상 버전·길이·체크섬 등의 전체 검증을 대신하지 않음을 설명했다. 전체 첫 바이트 비교의 비정상 Version 반례는 정수 계산이며 필터 엔진 수용 결과가 아니다.
- SYN/ACK 관측을 응용 서비스의 성공으로 확대하지 않고, 포트4444만으로 프로그램 정체를 확정하지 않았다.
- 마스크 사용이 항상 필수이거나 유일한 수학적 수단이라고 일반화하지 않았다.

확인한 근거는 libpcap·tcpdump 공식 저장소의 매뉴얼, Wireshark 공식 캡처 필터 안내, RFC791·9293 및 pcap-filter 매뉴얼 미러다. 확인일과 해당 링크를 본문에 연결했다.

## 바이트·계산 검산

0~255 전체256개 바이트에 대해 아래 니블·위 니블·길이 비교·SYN 포함의 네 관계를 검산했다. 01bb의 네트워크 순서443과 반대 순서47873, IHL 단위와 바이트 변환도 대조했다. 이 검산은 저장된 바이트와 정수 연산이며 tcpdump/libpcap 필터 엔진의 실제 실행과 구별한다. GUI·필터 엔진·VM 동작은 실행하지 않았다.

## 본문과 게시 확인

설명과 반례·풀이·복습을 연결한 본문은 약21,500자, 24개 절(참고 포함), 표8개, 자체 개념도3개, 즉시 읽는 복습14문답이다. 글자 수는 깊이를 확인하는 보조 정보이며 항목 대응과 풀이를 대신하는 통과 기준이 아니다.

HTML 태그·ID·내부 링크와 기존 앵커, 다른 본문의 보존, 목차 번호 중복 방지를 검사했다. 39개 생성 페이지의 내부 앵커1,238개 검사와 별도 회차 검사가 통과했고, 현재 main의 내용 해시와 대조해 바뀐 본문은 노트25뿐이며 다른38개 본문은 보존됨을 확인했다. 노트26~39의14개 대기 안내와 다음 회차 기록도 확인했다.

브라우저의 실제 렌더 DOM에서 데스크톱1280px·모바일390px의 문서 너비, 표8개와 그림3개의 내부 가로 스크롤, 목차 list-style:none을 확인했다. 글꼴 로드 완료 상태에서 세 SVG의 모든 텍스트가 각 그림 경계 안에 있음을 렌더 좌표로 검사했다. 다만 Page.captureScreenshot이 기존 탭과 새 탭에서 반복 시간 초과하여 이번 회차의 스크린샷 시각 검토는 완료하지 못했다. 이를 시각 검토 통과로 기록하지 않는다. 후속 실행에서 화면 캡처 기능이 회복되면 이 회차의 시각 검토도 보완한다.

최신 main을 기준으로 반영하고 실제 배포·게시 상태를 확인한 뒤 성공 범위를 보고한다. 다음 상세 개정은 노트26, 둘째 날4강이다. 나머지14강은 상세 개정 대기를 유지한다.
