## 공식 문서 현재 확인

2026-11-02에 아래 1차 자료를 실제 열어 확인했다. 본문 출처 12개에 링크와 확인 날짜를 반영했다.

- Wireshark 사용자 가이드: Follow Stream, Find Packet, TCP Reassembly, Export Objects.
- Wireshark 공식 TLS 위키와 `wireshark-filter` 매뉴얼.
- RFC 5321(SMTP), 6266(Content-Disposition), 9110(HTTP 의미), 9112(HTTP/1.1), 9113(HTTP/2), 9114(HTTP/3).
- 특히 Follow의 Back은 이전 필터 복원, Close는 현재 필터 유지, Raw의 화면 표시와 Save As의 바이너리 저장 차이를 확인했다. Find의 Selected Packet 검색 범위 제약을 설명했다.
- HEAD 응답에 Content-Length가 있어도 실제 응답 본문이 있다는 뜻은 아니다. Transfer-Encoding의 메시지 경계와 Content-Encoding의 표현 인코딩을 구분했다. Content-Disposition 파일명은 신뢰할 저장 경로가 아니다.
