## 자료 역할과 이전 기록

기존 7강 검토와 워크북 보충 검토를 읽었습니다. 워크북의 Wireshark 탐색·계층·대화 통계 목표와 첫째 날 PCAP 6개/621기록의 기존 오프라인 검증을 확인했습니다. 이번 실행에서 원본 워크북·PCAP을 다시 분석하지 않았습니다. 기존 여섯 캡처 검증을 이 단원의 별도 HTTP 피싱 사례 캡처를 직접 실행한 것으로 바꾸지 않았고, 실습자료 전체가 미제공이라고 단정하지 않습니다. 공개 22강 연계 링크를 유지합니다.

기존 7강의 해당 피싱 실습 입력에 대한 한계는 특정 사례의 입력 범위로 유지합니다. 이번 원문 대조·가상 수치 검산과 과거 PCAP 검증은 구분합니다. 구체적인 원문 파일명·문자열·실제 주소·내부 경로는 새로 공개하지 않습니다.

## 기존 설명 보존과 상세 보강

기존 본문·표4개·SVG1개·복습6문답·실습 링크·출처6개를 보존했습니다. 기존 문단·표셀·목록·코드·그림 설명의 문자열 보존을 검사했고 공식 확인 날짜만 갱신했습니다. 추가10문답으로 총16개와 바로 읽는 해설을 제공합니다.

새 SVG는 기존 가상 파일 10:00~10:20 UTC의1,200초 축에서 상대840초인 후보와12초 구간을 표시합니다.600픽셀 축에서 시작은420픽셀 지점,구간폭은6픽셀입니다. 점선은 경과시간이며 연속·완전수집 증명이 아님을 명시합니다. 총SVG2개이며 제목·방향·단위·범례·본문 설명을 포함합니다.

주요 보강은 자료 범위·메타데이터·해시의 한계,세 종류 분모,평균과 분포,길이와 속도의 단위,계층 포함과 마지막 해석,종단과 대화,필터 제한과 열 기준,우선순위와 실제 영향의 분리입니다. 관측·가설·미확인을 남기며 포트·색·문자열·응답부재로 침해·실행·반출을 확정하지 않습니다.

## 공식 출처 확인

2026년11월2일 본문 기존6개 공식 출처를 실제 열고 Capture File Properties·시간 형식·Protocol Hierarchy·Conversations·TLS·실행 인자를 대조했습니다. 추가 Endpoints 공식 가이드도 열어 계층별 종단 정의와 Protocol선택·프로필 저장을 확인했습니다. Conversations의 필터 제한·Rel/Abs Start·Duration·방향별 bits/s는 공식 검색과 문서로 재확인했습니다. 총7개 참고 링크와 실제 확인 날짜를 본문에 제공합니다.

원문의 통계 이용 원리는 유지하되 탭이 없으면 데이터도 없다는 일반화는 피합니다. 날짜가 오래된 교재 설명과 현재 문서의 표시 설정을 구분합니다. 특정 최신 릴리스 번호·모든 설치 환경의 동작·실행 성공은 추측하지 않습니다.

## 실제 검증

- 최신 scripts/build_notes.py로23개 노트와 목록 생성.
- 23개 노트·첫 화면 HTML 태그 중첩·중복ID·로컬파일/앵커 검사 통과.
- 기존 설명 문자열 보존,표4개 캡션/스크롤 래퍼,SVG2개 XML·제목·시간축 척도·설명과 기존 overflow CSS 확인.
- 시간 20×60=1200,840/60=14,후보10:14:00~10:14:12,상대14.2초→10:00:14.2를 datetime으로 검산.
- 120000−100000=20000,100000/1000=100,120000/1000=120kB,120000/1024=117.1875KiB 검산.
- 100+100+80=280%,54000/60000=90%,25/1000=2.5%,3/25=12%,3/1000=0.3% 검산.
- 별도 평균예제90×100+10×1000=19000,평균190 검산.
- 첫두행65000,A→B17000/B→A60000/전체77000 검산.
- 전체가상집계100000×8/1200≈666.67bit/s,별도12초행 합산40000·방향별4000/36000bit/s를 Decimal 등으로 검산. 최대속도나 실제파일크기로 해석하지 않음.
- 파일열기 두명령은 Bash -n구문검사와 공식문서 대조. Wireshark/tcpdump/TShark 실행파일이 없어 GUI·실제PCAP·통계창을 실행하지 않음.
- 브라우저 초기화가 읽기전용 파일시스템 오류로 실패. 데스크톱·모바일 화면 시각검증 미수행,우회미사용. 구조검사를 시각검증으로 보고하지 않음.
- 개정완료1~7·다음8과첫째날1~22대상 일치 확인. 다른강의와둘째날23강이후 본문은 변경하지 않음.
