## 기존 본문 보존과 개선

기존 11절의 학습 포인트를 13절로 연결해 설명했습니다. 주소·시간·ID·순번, 옵션과 필터, 생성 도구의 조건, LOTL, SYN 응답, 터널 구조, SSH, 조사 연표, 우선순위, 증거 구분과 복습을 모두 유지·확장했습니다. 기존 section anchor(start, reasoning, sweep, read-pcap, fingerprint, syn, tunnel, timeline, priority, evidence, review, references)는 유지하거나 별도 alias를 둡니다. 실습22강 링크와 전체 목차·1강/3강 이동을 유지합니다.

추론 보완: 무응답=무해, 기본 도구=낮은 숙련도, 모르는 도구=고급 공격, 기본 Nmap 패턴 불일치=완전 배제, SSH 문자열=접속·명령·유출 성공이라는 단정을 피했습니다. 데이터 검색과 재조립·관측 조건도 설명합니다. 교재에 나오는 특정 터널 구현을 모든 터널의 바이트 형식으로 확대하지 않습니다.

## 검증

- 본문 작성본의 제목·문단·표 셀·코드 등 331개 텍스트 단위가 HTML에 보존되는지 대조했습니다.
- 본문 13절, 표 11개, SVG2개, 복습13문항과 즉시 읽는 해설13개를 포함합니다.
- Python Decimal로 0.5ms·1ms·0.75ms를 검산했습니다. Echo 64−8=56, IPv4 20+64=84, ASCII8바이트와 SSH 시작8바이트를 대조했습니다.
- SSH 식별 문자열16바이트+CRLF2바이트=18바이트를 검증했습니다.
- HTML·중복ID·로컬 파일·앵커·참고 링크·SVG XML과 모바일 내부 스크롤 구조를 점검합니다.
- tcpdump·TShark 실행 파일이 이 환경에 없으므로 명령·필터는 공식 매뉴얼로 대조했으며 실제 PCAP 실행이나 GUI 검증으로 표시하지 않습니다. 원본 워크북·PCAP의 기존 검증과 이번 검산을 구분합니다.
- 이전 시도에서 미리보기 relay와 브라우저 실행 환경이 작동하지 않았습니다. 이번 브라우저 시각 검증은 수행하지 않습니다.
- 원본 PDF·워크북·PCAP·OCR·스크린샷·개인 경로를 공개하지 않습니다. 공개 설명은 자체 예시입니다.
