# 셋째 날 3강 교재 대조와 실습 검증 · 2026-11-19

셋째 날 교재의 인쇄 26~35쪽(PDF 28~37쪽) 내장 텍스트와 그림·표·화면을 직접 대조했다. 별도 원본 PCAP·워크북은 접근하지 못했다. 공개 예제는 브라우저 요청과 메일 첨부의 독립적인 가상 텍스트만 사용했다.

| 교재 범위 | 학습 목표 | 본문 절·검증 |
| --- | --- | --- |
| 26~27쪽 | HTTP 객체 목록, 행 선택과 출력 저장 | `layers`, `http`. 응답 본문 경계와 원래 프레임 대응 |
| 28~29쪽 | 도구 누락·불일치, 추출물의 조회 범위·형식 확인 | `limits`, `validation`. 현재 재조립·버전·가시성 조건, 안전한 바이트 검사와 해시 |
| 30~31쪽 | 직접 추출이 필요한 경우, SMTP와 MIME | `mime`. SMTP 프레이밍, 각 MIME 부분의 인코딩과 첨부 표기 |
| 32~34쪽 | TCP 대화 저장, 관심 방향과 헤더·경계·줄 끝 | `mime`, `validation`. 작업용 사본과 원래 메시지 보존, 부분의 경계를 직접 확인 |
| 35쪽 | Base64 해제와 파일 형식 확인 | `validation`, `review`. 로컬 명령으로 바이트 수·형식·해시를 독립 검산 |

HTML의 가상 HTTP·MIME 메시지에서 14바이트 본문을 각각 추출해 일치를 확인했다. 분할·동일 재전송 표본을 바이트 위치로 합쳤으며 관측 합 22바이트와 본문 14바이트를 구분했다. 본문에 표시한 GNU Coreutils 9.7과 file 5.46 명령을 실행했고 SHA-256과 ASCII 텍스트를 확인했다. Wireshark GUI·TShark 엔진은 실행하지 않았다. Wireshark 공식 매뉴얼과 HTTP·SMTP·MIME 관련 RFC를 2026-11-19에 조회했다.

## 공개 검증

두 강의 콘텐츠가 포함된 커밋의 GitHub Pages 성공을 확인했다. 공개 목록, 새 두 강의와 연결을 갱신한 2강이 HTTP 200을 반환했고 생성 파일과 바이트 단위로 일치했다. HTML 250개와 내부 링크·앵커 22,584개를 검사했다. 기존 본문과 메타데이터를 보존하고 일차별 번호와 두 강의 연결을 확인했다.

공개 데스크톱 및 좁은 CSS 화면을 직접 확인했다. 넓은 표와 그림은 문서 전체 가로 넘침 없이 내부 스크롤로 내용을 읽을 수 있었다. 물리 모바일 기기와 터치는 시험하지 않았다.
