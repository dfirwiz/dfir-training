## 근거와 정확성

- 원본 교재의 해당 장 전체 텍스트를 비공개로 읽어 주제와 기존 본문을 대조했다. 원문·이미지·파일명·식별자는 공개 파일에 추가하지 않았다.
- Microsoft PE 형식, 가상 주소 공간, 페이지 상태, 접근 토큰, Windows 자료형, 형식 마샬링, GetFileAttributesW, QueueUserAPC 및 MITRE T1055.003/T1055.012를 2026-11-03 확인했다. 관련 공식 링크는 각 강의 근거 절에 유지·보강했다.
- 교재의 ANSI=UTF-8, 단순 Sleep=alertable, 고정 PEB 오프셋 일반화 등 기존 본문이 보정한 설명을 그림에 재도입하지 않았다.
- RVA 0x1120의 섹션 내부 위치는 0x120, 파일 위치는 0x320. RVA 0x1350은 0 채움 구간으로 파일 위치 계산을 하지 않는다.
- 구조체 예는 Windows x86/x64 기본 정렬, Pack 별도 지정 없음, DWORD와 포인터만으로 명시했다. 8/16바이트는 가정에 따른 계산이며 Windows/C# 실측이 아니다.
- 주입 관련 그림은 분류·증거·상태 비교이며 실행 코드나 구현 절차를 추가하지 않는다. 정상 재배치·JIT·관측 한계도 설명한다.
