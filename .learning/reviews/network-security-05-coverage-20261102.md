# 네트워크 보안 분석 5강: 독립 DNS 실습 검토

## 원문과 자료의 역할

2권 인쇄 86~87쪽(PDF 88~89쪽)은 로드맵과 별도 워크북/가상 위키 실습 안내입니다. 접근 가능한 교재 폴더의 모든 파일과 작업 폴더의 관련 PCAP/워크북 이름을 다시 확인했지만 별도 실습 원문과 패킷을 찾지 못했습니다. 따라서 알려지지 않은 워크북 문제·목표·정답을 재현했다고 주장하지 않습니다. 3~4강에서 설명한 원리를 독립적인 합성 실습으로 연결했습니다. 다음 원문 범위는 인쇄 89~106쪽의 HTTP 원리입니다.

## 자체 자료

`scripts/build_dns_lab.py`는 네트워크 I/O 없이 PCAP 두 개와 가상 보조 로그를 만듭니다. 문서용 IPv4/IPv6 주소와 example 이름만 사용했습니다. TXT에는 무해한 고정 표식을 넣었습니다. 단말 쪽 46프레임, 상위 구간은 두 대화만 선택한 4프레임입니다. 상위 파일의 부재를 전체 연속 수집에서의 부재로 해석하지 않도록 명시했습니다.

`scripts/inspect_dns_lab.py`는 생성 코드와 분리된 dpkt 1.9.8 해석으로 주소·포트·ID·이름·종류·코드·TTL·답을 읽습니다. IPv4와 전송 계층 체크섬을 검증하고, 주소·포트 방향/프로토콜/ID/질문으로 응답을 연결합니다. 이 실습의 완전한 TCP 메시지만 읽으며 범용 TCP 재조립을 구현한 것으로 주장하지 않습니다.

11개 파일의 ZIP을 제공합니다. 패킷 해석 CSV와 단말·자산·연결의 가상 맥락 CSV를 구분했습니다. 한국어/영어 안내문과 SHA-256 비교값을 포함했습니다. ZIP 내부 파일·원본 파일 일치와 압축 CRC를 확인했습니다. 원본 교재·화면은 게시하지 않습니다.

## 실습 범위 대응

- 1~4절: 이전 원리 연결, 워크북 접근 한계, 자료·도구·UTC·해시, 두 센서와 역할별 경로
- 5~7절: 같은 ID와 뒤바뀐 응답, CNAME/복수 A/AAAA, 후속 연결의 한계, PTR 복원
- 8~10절: NOERROR/NODATA/NXDOMAIN/응답 미관측 구분, 재시도와 질문 행의 단위, TTL 감소의 가설 한계
- 11절: 정상 이름의 비인가 리졸버 사용, 전달 서버의 정상 상위 질의와 구분
- 12~14절: 긴 TXT 두 집단, 고유 이름 비율, CSV 실습, 가상 실행 기록과 실제 유출 성공 구별
- 15~17절: 중간 레이블의 IDN, UDP 잘림/TC와 TCP 연결·DNS 길이 필드, 상위 출발지/ID 변경과 선택 사례의 한계
- 18~20절: TShark 내보내기의 복수 필드, 0행의 관측 한계, 사실·가설·미확인 결론의 조사 메모
- 21~22절: 조건을 바꾼 복습 16문항·즉시 해설, 실행/미실행 범위와 다음 HTTP 강의

## 실제 실행 결과

dpkt 1.9.8: 단말 46프레임, DNS 메시지 42개, 질문 22행·응답 20행, 응답 미관측 질문 프레임 15·16, 비인가 단말 질의 13, collect 하위 질문 8행·고유 이름 6개(75%), NXDOMAIN 응답 1/20(5%), TC 응답 40, TCP DNS 프레임 44·45, 상위 4프레임·질의 출발지 192.0.2.53을 확인했습니다. 첫 네 메시지는 1→4, 2→3으로 대응합니다. 모든 IPv4/UDP/TCP 체크섬 검증을 통과했습니다.

PowerShell의 본문 CSV 계산을 직접 실행해 8·6·0.75를 얻었습니다. Get-FileHash SHA256으로 단말 파일의 c7bf3e2ceef94a256e50f392c523571ce87d19b5aada1df0e9a2077416162193 값을 확인했습니다. manifest의 모든 비교값과 ZIP 멤버의 바이트 일치도 검증했습니다.

## 공식 근거와 최신 확인

2026-11-02에 Wireshark 시간 표시/이름 해석/표시 필터/DNS 필드·버전, TShark 공식 옵션, RFC 1035·2308, dpkt 1.9.8 배포·프로젝트 문서, Microsoft Import-Csv·Get-FileHash를 확인했습니다. dns.response_missing은 4.4.0 이후라는 조건을 명시했습니다. DNSSEC·DoH/DoT/DoQ 일반 탐지 성능을 이 파일로 검증했다고 주장하지 않습니다.

## 사이트 검증

22절·98문단, 표 3개, 코드/명령/표시/계산 블록 13개, 자체 SVG 4개, 복습·해설 16개를 확인했습니다. 본문 전체 렌더링과 코드 보존, XML, 내부 링크·앵커·자료 링크, 공개 본문 식별자 노출, 1~4강 교육 본문 동일 여부를 검사했습니다. 로컬 데스크톱과 390px 모바일에서 그림 4개와 목차·이전 강의·다운로드 링크를 확인했습니다. 문서 가로 넘침 없이 넓은 표·코드는 내부에서 스크롤됩니다. 공개 배포 완료는 게시 작업과 공개 URL로 별도 확인합니다.

## 수행하지 않은 것

Wireshark/TShark 실행 파일을 이 환경에서 확인하지 못했으므로 해당 필터·명령을 실행했다고 쓰지 않았습니다. 실제 DNS 조회·라이브 캡처·패킷 재전송·외부 지표 제출·TLS 복호화·악성 프로그램·실제 파일 유출은 수행하지 않았습니다. 실제 분석은 자체 생성 파일을 대상으로 했고 보조 단말·연결·자산 기록은 가상 조건입니다.
