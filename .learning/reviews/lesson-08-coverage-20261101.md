# 8강 원문 대응과 검토 기록

확인일: 2026년 11월 1일. 최신 main의 편집 기준·진행 정보·과정 목록·생성 스크립트, 상세 보강된 1·2·3강과 직전 7강 본문을 확인했습니다. 이번 범위는 인쇄 62~70쪽 / PDF 64~72쪽입니다. 전체 OCR과 페이지 이미지, 특히 SMTP 방향·검색 옵션·HTTP 헤더가 있는 화면의 개별 이미지를 대조했습니다. 원본 화면과 OCR 전문은 공개하지 않습니다.

원문의 검색 문자열은 페이지 간 표기와 OCR 결과에 불일치가 있어 그림과 본문을 대조했습니다. 독립적인 filename=notice.pdf 예시로 검색 원리를 설명하고 원본 PCAP 검색 성공을 주장하지 않습니다. 화면의 표식이 서버 응답 헤더라는 위치를 반영해, 모든 파일명 표식을 요청 URL로 오인하지 않도록 설명했습니다.

원문 SMTP 대화의 실제 계정·주소·도메인을 복제하지 않았습니다. 예시 도메인과 가상의 메일 봉투 주소로 바꾸었고 SMTP 최종 전달·사용자 읽기까지 확인했다고 쓰지 않았습니다. SMTP 확장 기능 전체는 이번 목표가 아님을 밝혔습니다.

## 현재성 보완

공식 Wireshark의 Follow·Find Packet·Reassembly·Export 문서와 TLS 문서, RFC 5321·6266·9110·9112·9113·9114를 조회했습니다. 링크와 확인일은 본문에 포함했습니다.

- Follow는 여전히 유용합니다. Close와 Back의 필터 동작, 테마별 색상, 방향·표시 형식·저장 방식은 구분합니다.
- String / Packet bytes를 모든 검색의 필수 기본값으로 일반화하지 않았습니다. 검색 질문에 맞는 방식과 영역을 고르고 현재의 선택 패킷 내부 검색 제한도 확인합니다.
- Packet bytes는 페이로드만이 아니며, 개별 패킷 검색과 재조립된 메시지 검색을 구분합니다.
- 번호는 파일·해석 조건 안의 식별값으로 보고 원본 해시·설정·시각·종단을 함께 기록하도록 보완했습니다.
- HTTP/1.1 예제를 현재의 모든 웹 통신으로 일반화하지 않고 TLS·HTTP/2·HTTP/3의 적용 차이를 설명했습니다.
- Export Objects는 이 범위의 원문 절차 자체가 아니라 객체를 조사하는 후속 보충으로 명시했습니다. 실제 객체 추출 결과나 해시를 꾸며내지 않았습니다.

## 예제·계산과 증거의 한계

HTTP 예시는 일반적인 GET 응답이며 본문은 생략한 부분 예시입니다. Content-Length 9000과 실제로 확보한 본문 3000바이트를 가정하면 차이는 6000바이트입니다. Transfer-Encoding·압축이 없는 단순 조건을 명시하고 다른 메서드·상태·프레이밍에는 같은 계산을 강제하지 않았습니다. 이 차이를 실제 미전송이나 공격 실패로 단정하지 않습니다.

filename=not과 ice.pdf를 이어 filename=notice.pdf가 되는 예로 패킷 경계 검색의 한계를 설명했습니다. SMTP·HTTP 메시지와 패킷·스트림 번호, 파일명은 모두 자체 구성한 가상 예시입니다. ASCII 표시·Raw 스트림·HTTP 객체·캡처 저장을 같은 결과물로 취급하지 않습니다.

200 OK·파일명 제안·확장자·제품 알림·대화 색상으로 공격 성공·실제 파일 형식·사용자 신원·공격자 수준을 확정하지 않습니다. 실제 저장과 실행은 단말·서버 자료로 확인할 별도 단계입니다.

별도 워크북과 PCAP이 없어 원문 연습과 실행 결과는 확인하지 못했습니다. 제공된 원문 페이지의 학습 범위와 별개로 이 실습 한계를 명시했으며, 자체 복습 8문항과 해설을 본문에 직접 표시했습니다.

## 검증과 진행

홈페이지와 노트 8개, 로컬 링크·자산 380개, 새 노트 14절·참고문헌 11개·복습 8문항을 검사했습니다. 중복 ID·누락 앵커·없는 내부 링크가 없고, 표와 SVG의 구조·접근성 제목, 코드 표기·계산·순차 진행 상태를 확인했습니다. 기존 폰트·어두운 배경·민트 강조와 반응형 스타일을 유지합니다.

미리보기 인프라 제한으로 실제 브라우저 시각 검증은 수행하지 못했습니다. 구조 검사를 시각 검증 완료라고 보고하지 않습니다. 이번 완료 지점은 인쇄 70쪽이며 다음은 9강 인쇄 71쪽부터입니다. 전체 16회차 계획과 최종 167쪽 범위는 유지하고, 학습 상태는 진행 중입니다.
