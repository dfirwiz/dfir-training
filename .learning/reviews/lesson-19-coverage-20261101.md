## 공식 현재성 확인

- tcpdump 공식 매뉴얼 소스를 읽어 -r의 표준 입력, -w의 캡처 출력, -c 제한을 확인했습니다. 바이너리 캡처와 디코딩된 텍스트를 같은 자료형으로 취급하지 않습니다.
- capinfos 공식 매뉴얼에서 기록 수·최초/최종 시각·기간·오류 동작을 확인했습니다. 공식 capinfos.c의 순차 읽기와 wiretap/file_access.c의 파일명 '-' 표준 입력 처리도 읽었습니다. 모든 형식의 파이프 처리를 보장하지 않으며 실제 설치 실행 검증과 구별했습니다.
- TShark 공식 문서의 -2는 되돌아 읽기가 필요해 파이프/FIFO에 사용할 수 없다는 제한을 예로 연결했습니다. 원문의 하이픈 일반화를 프로그램별 약속으로 수정했습니다.
- GNU Grep 공식 사용 지침·매뉴얼과 공식 3.8 공지에서 egrep/fgrep의 오래된 명칭과 2022년 경고를 확인했습니다. 현재 명령은 grep -E/-F를 명시하며 강제 별칭을 제안하지 않습니다. BRE·ERE를 단순한 약함/완전함의 순위로 설명하지 않습니다.
- GNU sed 공식 치환 설명·매뉴얼과 로컬 도움말을 대조해 -e, s, g, 기본 출력과 제자리 수정의 차이를 확인했습니다. 일부 GNU 문서 직접 열기는 시간 초과였으며 검색 도구가 반환한 공식 문서 본문과 로컬 실행으로 대조했습니다. 실패한 직접 열기를 성공했다고 주장하지 않습니다.
- Zeek 공식 FAQ로 이름 변경 시점을 대조했습니다. 현재성을 확인한 날짜와 공식 근거 9항을 본문에 기록했습니다. 이는 확인 시점의 문서·소스 설명이며 특정 도구 실행 결과가 아닙니다.

## 실제 검산과 구조 검사

- 문서용 주소만 있는 자체 events.txt 세 줄을 정의했습니다. GNU grep 3.11, GNU sed 4.9, C.UTF-8 환경에서 실행했습니다. tcpdump·capinfos·TShark는 설치되어 있지 않으며 전용 VM·실습 PCAP도 없어 패킷 명령은 실행하지 않았습니다.
- grep -E 'ALLOW|DENY'는 3줄, grep -F '192.0.2.10'은 1줄을 선택했습니다. ABSENT는 빈 출력/상태 1, 없는 파일은 오류/상태 2를 확인했습니다. 추가 주소 192.0.2.100도 앞 주소 문자열에 부분 일치함을 검산했습니다.
- sed에서 g 없이 각 줄의 첫 콜론만 바뀌어 3곳, g를 쓰면 각 줄 3개씩 3×3=9곳이 바뀌었습니다. 세 줄의 전체 결과와 첫 줄의 중간 결과를 본문과 대조하고 실행 전후 입력 해시가 같은지 확인했습니다. cat 파이프와 직접 입력 결과도 같습니다.
- 생성 스크립트로 공개 노트 19개와 전체 목록 20개를 재생성했습니다. 태그 균형·중복 ID·페이지별 h1·모든 로컬 파일/앵커, 표 caption/thead/tbody·열 제목, SVG XML·접근성 제목을 검사했습니다. 새 본문 14절·표 3개·SVG 2개·참고 9항·직접 보이는 질문 10개이며 주요 해설을 접힌 UI에 숨기지 않았습니다.
- 기존 폰트·어두운 배경·민트 강조·반응형 및 가로 스크롤 스타일·생성 스크립트를 유지했습니다. 미리보기 인프라가 없어 실제 브라우저 시각 검증은 수행하지 못했으며 구조 검사와 구별합니다.
- 범위는 기존 계획 그대로 155~158쪽입니다. 이전·다음 링크와 목록 공개 상태 외 기존 강의 본문을 변경하지 않습니다. 공개물에 원본 전문·이미지·업로드 식별자·타사 과정 번호·개인정보를 추가하지 않습니다.
