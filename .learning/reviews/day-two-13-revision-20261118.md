# 둘째 날 13강 상세 개정 검토 · 2026-11-18

최신 main의 편집 기준·둘째 날 진도 전체·과정·직전12강 본문과 검토·대상13강·최신 생성기를 읽었다. 직전 변경의 Pages가 completed/success이고 보류 상태가 없음을 확인했다. 다음 미완료13강 한 강의만 상세화한다. 게시 전 완료 목록은12강까지 유지한다.

## 이번 직접 확인과 과거 자료 구분

원격 본 교재를 새로 확보하여 인쇄142~152/PDF144~154 전체 설명을 읽고11쪽 모두를 원본 바이트에서 렌더한 두 접촉시트로 대조했다. 원격 읽기에서 마지막 쪽의 이미지가 없다는 경고가 있어도 해당 쪽의 실제 원본 렌더를 직접 보았다. 기존 교재 화면·문장·주소·숫자·독점 문제를 복제하지 않고 새 문서용 주소·숫자·도식·복습을 작성했다.

워크북/PCAP 일반 검색은 교재 내 언급을 반환했고 제목 한정 검색에서는 해당 원본 파일을 찾지 못했다. 자료가 처음부터 미제공이었다는 뜻이 아니다. 기존 day-two-complete의 축약본 완료 주장 철회 및 여섯 파일1067레코드의 과거 오프라인 검사와 직전 항목별 검토를 읽었다. 이번에는 원본 워크북·PCAP을 재실행하거나 문항 전체를 최종 대조하지 않았다. 독립 예제의 수치 검산과 실제 필터엔진·대상 호스트의 동작을 구분한다.

## 공식 문서 확인 · 2026-11-18

본문에 RFC792/1122/1812/1191/4884/4443/4890, IANA ICMP등록표, libpcap 제작사 필터 문서, Wireshark 표시필터/IPv4필드/TShark 문서, Microsoft tracert 문서 링크를 제공한다. 모두 실제 조회했다. tcpdump 웹매뉴얼은 robots 제한이 있었으므로 실제 읽은 제작사 저장소의 libpcap 공식문서를 사용했다. 설치하지 않은 버전의 필터 지원을 실행 확인했다고 쓰지 않는다.
