## 직접 실행한 자체 검증

Python3.12.14.9강 본문 코드를 그대로 추출 실행: weighted20/min6/max30, 자체 정규화 점수58.33. 공식 NCISS 구현·공격 확률·실제 위험 평가가 아님. 시간 예제25/8/50/42/75분도 datetime으로 검산.

10강 assets/network-security/lab10의 JSON2개·review_case.py·README.txt는 독립 제작한 무해한 자료이다. 가상 사실3개와 관측값2개, 작업3개(필수2개)로 구성. TheHive API 형식이나 실제 사건 자료가 아니다.

- case-start.json: 종료2, T2 미완료/결과/근거와 전체 요약 누락, REVIEW BLOCKED.
- case-reviewed.json: 종료0, REVIEW READY (record checks only). 입력 상태는 계속 in_progress이며 파일·제품 상태를 바꾸지 않음.
- 상태만 completed로 바꾼 복사본: 종료2, 결과/근거/요약 누락이 남음.
- 잘못된 JSON: 종료2, INPUT ERROR: JSONDecodeError.
- 두 입력 모두 가상 자료이며 모든 주소·도메인은 문서용/예시 범위. 인터넷·DNS조회·보안 제품·분석기·대응기·실제 계정·VM·PCAP·공격·차단·외부 연락 실행 없음.
- 검사 조건의 한계를 본문에 명시: 빈 전체 작업 목록·중복ID·모든 형식/권한/이력·실제 근거 진실성까지 검증하지 않음. 통과를 조사 성공/정상/복구 확정으로 표현하지 않음.
