# 셋째 날 10강 교재 대조와 검증 · 2026-11-20

인쇄 104~114쪽(PDF 106~116쪽)의 설명과 프레임 도식, 도구 화면과 실습 안내를 대조했다. 내부 캡처나 원래 화면 대신 독립적인 가상 바이트와 도식을 작성했다.

| 교재 범위 | 학습 목표 | 본문과 검증 | 잔여 |
| --- | --- | --- | --- |
| 104~106 | 다중화와 헤더 압축, HTTP/2 프레임 구조와 방향 | `question`, `http2`. 9바이트 머리말과 14바이트 프레임 독립 검산 | 실제 캡처 재조립 미실행 |
| 107~109 | 이전 업그레이드와 현재 시작 방식, 의사 헤더·가시성 | `negotiation`. 표준에서 이전 업그레이드 폐기와 필드 명칭 확인 | 구형 캡처 직접 비교 미수행 |
| 110~113 | QUIC과 HTTP/3, 프레임 위치, 스트림 ID·오프셋·도구 지원 | `quic`, `visibility`. 하위 비트와 데이터 경계 검산, 버전별 문서 확인 | 실제 복호화·성능·가시성 시험 미수행 |
| 114 | HTTP 규칙 실습 연계 | 9강 `detection` 및 10강 `review`. 합성 HTTP 요청과 관측 필드를 비교 | 워크북 원본 문항과 캡처를 이번 실행에서 확보하지 못해 대응 미확인 |

RFC와 제작사 문서를 2026-11-20에 확인했다. 교재 당시의 QUIC 해석 설명에서 패킷/프레임의 위치, 가변 길이와 암호화를 현재 RFC로 바로잡았다. 패킷 해석기나 탐지 엔진을 실행한 결과는 포함하지 않았다.
