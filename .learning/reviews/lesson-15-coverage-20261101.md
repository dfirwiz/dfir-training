# 15강 원문 대응·검증 기록

확인일: 2026년 11월 1일. 최신 main의 편집 기준·진행·과정·생성 스크립트와 상세 보강된 1·2·3강, 직전 14강 및 2·3강의 압축·생략 검토 기록을 확인했습니다. 최신 진행점에 따라 이번 실행은 15강 하나만 완료합니다. 본문은 정의·필요성·작동·예시·관측에서 판단까지의 과정·전제와 한계를 연결하고, 표로 설명을 대체하지 않습니다.

## 현재성 대조와 판단 제한

- IPv4 Total Length·IHL·원시 Offset의 단위와 기본 계산은 현재도 유효합니다. 2021년 이후 필드가 바뀐 것처럼 설명하지 않았습니다.
- 공식 tcpdump 매뉴얼과 IPv4 해석 소스를 조회해 옵션, 상세 출력에서 원시 Offset을 이미8배하는 처리, 첫 조각과 뒤 조각의 상위 프로토콜 해석 구분을 확인했습니다. 단순한 문자열 복제가 아닌 바이트·계층 범위를 설명했습니다.
- MTU까지 채우는 예제와 모든 조각이 같은 크기여야 한다는 주장을 구별했습니다. RFC791·RFC1812의 다른 분할 방식과 재단편화 가능성을 반영했습니다. 앞 위치1480이 앞 조각 하나를 증명하지 않습니다.
- RFC815의 구간·빈틈 관점, RFC6864의 ID 문맥, RFC792의 Echo 헤더, Wireshark의 IPv4·프레임 필드와 재조립·SnapLen·TLS 문서를 확인했습니다. 과거 Wiki의 낡은 기본 SnapLen이나 기본 재조립 설정을 현재 고정값으로 옮기지 않았습니다.
- RFC8900은 2020년 문서이며 현재의 단편화 운영 한계를 설명하는 근거로 사용했습니다. 최근에 새로 발견된 문제라고 하지 않았습니다. DSCP/ECN은 RFC2474·RFC3168로 대조했습니다.
- 재조립·복호화·대상 수신·응용 처리를 구분했습니다. 사용자 질문인 현대 패킷 분석의 가치와 암호화의 한계를 관련 본문에 연결했습니다. 크기·도구·무응답만으로 공격자 숙련도·무해함·성공을 단정하지 않습니다.
- 확인일과 공식 근거15개를 본문에 붙였습니다. 패킷의 사실/단독 확정 불가/추가 로그를 별도 증거 구분과 가상 조사 메모로 설명했습니다.

## 계산·구조 검증

- 자체 A 헤더: IP길이1500, IHL20, 데이터1480, MF1, 원시Offset0, 데이터[0,1480), 헤더 체크섬268d.
- 자체 B 헤더: IP길이48, IHL20, 데이터28, MF0, 원시Offset185, 바이트1480, 데이터[1480,1508), 체크섬4b80.
- 자체 C 헤더: IP길이28, IHL20, 데이터8, MF0, 원시Offset2, 바이트16, 데이터[16,24), 체크섬4c4a. 표시한8바이트와 계산이 일치합니다.
- 세 헤더의16비트1의보수 합이ffff가 됨을 독립 코드로 검산했습니다. 이것은 자체 헤더 계산 검증이며, 생략한 ICMP 전체 체크섬이나 네트워크 실행·수신 검증이 아닙니다.
- 05dc=1500,0030=48,001c=28,00b9=185,185×8=1480,2×8=16과 원시 Offset 마스크1fff를 확인했습니다.
- 데이터1480+28=1508, 원래20+1508=1528, 조각IP합1500+48=1548, 추가헤더20, Echo헤더8을 뺀1500을 검산했습니다. 원래IHL5·같은묶음·정상Echo라는 전제를 명시했습니다.
- 앞부분800+680=1480과800/8=100, 끝이 아닌 데이터의8배수 조건을 검산했습니다. C의 끝24는 앞16바이트 확보를 증명하지 않습니다.
- 캡처 예제14+1500=1514,96−14−20=62, 미확보1480−62=1418을 검산했습니다. 선언 길이와 확보 길이를 구별했습니다.
- 생성 스크립트로15개 노트·18개 목록 항목을 재생성했습니다. 홈페이지+노트15개, 로컬 링크·자산856개와 앵커, 태그 균형·중복ID·각h1 하나를 검사했습니다. 새 본문은15절(참고 포함), 표3개, SVG2개, 근거15개, 본문에 직접 보이는 복습10개와 추가 연습을 포함합니다.
- 표caption/thead/tbody·열 제목, SVG XML과 접근성 제목·ID를 검사했습니다. 코드/표/그림의 가로 스크롤·반응형 스타일과 기존 폰트·색상은 유지했습니다. 실제 브라우저 시각 검증은 수행하지 못했습니다. 구조 검사와 시각 검증을 구분합니다.
- 공개물에서 타사 과정 번호·원본·OCR 전문·스크린샷·업로드 ID와 원본 주소를 제외했습니다. 새 본문의 잘못 섞인 외국어 문자도 점검했습니다.

## 완료와 다음 시작점
