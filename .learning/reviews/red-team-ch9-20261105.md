# 9장 Elevated Persistence 작성·검증 기록

- 원격 main 기준 시작점: 전역 ID1~37, 1~8장 완료.
- 활성 예약 파일은 앞 범위 완료·해제 상태였으며 ID38~39 중복 작업이 없음을 확인했다.
- 연결된 업로드 원본 9장 전체를 읽고 Scheduled Task와 Windows Service 두 범위로 분할했다.
- 공개 원문·이미지·파일 식별자와 제한된 과정 명칭은 사용하지 않았다.
- ID38: BootTrigger·Principal·Action·Settings, 등록·발생·프로세스·결과, Task Scheduler 실제 화면 3종과 Beacon Console.
- ID39: SCM 등록·자동 시작·서비스 계정·프로그램 계약·재부팅 검증, Beacon Console과 미확보 Services 화면의 한계.
- 각 11절, 복습·즉시 해설 8개, 독립 SVG 3개. 총 복습 16개·SVG 6개·공식 화면 5회.
- 실제 Windows·Cobalt Strike·작업/서비스 생성·파일 배치·부팅/재부팅·SYSTEM 실행·자격증명/보호 기능 변경은 수행하지 않았다.
- 빌드, course.json, 전역 ID 연속성, 장별 번호, 모든 내부 링크·앵커·이미지, SVG XML, diff 검사를 통과했다.
- 공개 배포와 공개 페이지·자산 검증 뒤에만 published_verified로 바꾼다.
