# 둘째 날 교재·랩 학습 목표 종합 점검 · 2026-11-18

둘째 날 교재를 원격에서 다시 확보했다. 인쇄 4~184쪽에 해당하는 PDF 6~186쪽 181쪽에서 내장 텍스트와 렌더링한 페이지의 주제·표·그림 구성을 확인했다. 최신 공개 본문 1~17강과 회차별 대응 기록을 함께 대조했다. 앞선 랩 직접 검토의 [23개 목표 대응표](day-two-labs-source-20261118.md)를 별도 근거로 사용하고 이번 교재 검토가 당시 랩 실행을 재현한 것으로 계산하지 않았다.

## 랩 목표와 새 종합 예제

| 앞선 직접 대조 범위 | 연결한 심화 강의 | 현재 적용 확인 |
| --- | --- | --- |
| 표시 필터 4개와 추가 1개 | 1~2강과 17강 `display` | 질의 이름과 요청만 구별, 저장 집합과 원본 복귀 |
| BPF 4개와 추가 2개 | 3~4·16강과 17강 `bpf`, `mask-extra` | 방향·마스크·DNS 오프셋과 조건 해석 |

| UDP/ICMP 4개와 추가 1개 | 11~13강과 17강 `udp-icmp`, `labs-source-refresh` | 오류 억제·경로·인용 대응·페이로드·정책 해석 |
| 교재의 종합 조사 목표 | 17강 `capstone-correlation` | 가상 장부에서 수집 지점의 시각·방향을 정렬하고 IPv4/IPv6 DNS와 TCP 교환을 각각 대응한다. 161−25=136, 136−120=16, 208−191=17 ms 및 양방향 번호 9000/6101을 검산했다. |

17강의 기존 본문·목차 주소·독립 복습을 보존하고 새 사례와 네 문답을 추가했다. DNS 질문과 답변 대응, ICMPv4 인용 구조, TCP 시작 번호, IPv6 주소 표기는 2026-11-18에 RFC 1035·792·9293·8200을 확인했다. 시각 표시의 기준은 Wireshark 제작사 안내를 확인했다. 모든 주소·숫자·기록은 독립적으로 만든 가상 표본이다.

## 완료 범위와 남은 근거

학습 목표 대조 범위는 교재 본문과 제공된 랩 PDF 네 개다. 교재 176·184쪽이 가리키는 별도 종합 실습 기록 자료·점수 서버 문항은 제공된 랩 PDF에 들어 있지 않다. 해당 원본과 실습 PCAP의 파일명 검색으로 재접근하지 못했다. 과거 여섯 파일의 오프라인 검토와 이번 두 시점 장부 검산을 구분한다. 엔진·가상머신·종단 실제 실행은 미수행으로 기록하며 전체 종료 상태는 별도 종합 자료의 확인 전까지 보류한다.

공개 17강에 남아 있던 이전 실습 원본 파일명과 원본별 레코드 번호·선택 수치는 새 가상 사례, 필드 검산 및 확인 기준으로 바꿨다. 예전 오프라인 검토가 있었던 사실과 현재 실행 한계는 보존했다.

## 공개 검증

GitHub Pages에서 본문을 반영한 커밋의 배포 성공을 확인했다. 공개 본문과 목록은 각각 HTTP 200이었고 생성 파일과 바이트 단위로 일치했다. 실제 공개 화면에서 데스크톱 1363×936과 좁은 CSS 화면 454×312를 확인했다. 좁은 화면에서 문서 폭과 스크롤 폭은 449px로 같았고, 새 장부의 내부 가로 스크롤은 0에서 약 171px까지 이동했다. 물리 모바일 기기와 터치는 시험하지 않았다.

생성기를 실행해 목록과 본문을 만들고, 줄바꿈만 달라진 다른 29개 생성 파일을 원래 바이트로 복원했다. HTML 242개와 내부 링크·앵커 22,333개 검사, 기존 14개 ID 보존, 표 제목·스크롤 영역, 새 장부 여섯 행의 수치와 복습 22개를 확인했다. 종합 실습 원문 확인은 보류 상태로 남겼다.
