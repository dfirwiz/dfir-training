## 원본 범위 대응 및 보정

- 원본의 주요 주제 모두를 위 6강에 대응했다. 생성·우회·숨김·자동 실행 패키지 코드는 배포하지 않고 구조·조건·실제 관측과 읽기 전용 분석으로 설명했다.
- 고정 DLL 검색 순서 대신 앱 유형·매니페스트·KnownDLLs·API set·로더 옵션 조건 확인. 실패 탐색과 실제 Load Image를 따로 필터링.
- Framework AppDomainManager와 현대 .NET 구별. 현재 프로세스 Env 조회를 과거 타 프로세스 환경 부재로 확대하지 않음.
- MSI 패키지 계획과 실제 설치·Custom Action 수행 구별. XLAM·Protected View·매크로 차단·신뢰 위치·서명 구별.
- OV/EV 서명도 현행 SmartScreen 경고를 없앤다고 보장하지 않음. ProgramData 전체의 사용자 쓰기 권한을 일반화하지 않음.
- GrimResource는 2024년 관측으로 명시하며 현재 모든 Windows 재현성·미패치·자동 권한 상승을 주장하지 않음.
- MotW 부재·조회 실패·invalid는 안전으로 판정하지 않음. 고정 컨테이너별 출처 손실을 보장하지 않음.
- SVG 이미지와 문서 문맥의 제한 구별. HTML 조립이 모든 네트워크/엔드포인트 관측을 피한다고 표현하지 않음.
- Host File 원본 주소와 격리 실습 가정을 분리. 텍스트만 예시로 사용하며 호스팅·전달·저장·실행·C2 세션 구별.

## 검증

- stdlib 빌드: 19강 모두 절·그림·복습 수 assert 통과.
- Python --demo 실제 수행: 동일 본문 SHA256, Internet/missing/invalid/Intranet 4가지 결과. 모든 실행·악성 판정은 미확인으로 표시.
- 누락·빈 텍스트·잘못된 ZoneId·중복 키·DEFAULT 값 상속·부호 문자열·크기 제한의 해석을 확인.
- 새 SVG 18개 XML·수동 구조 검토·브라우저의 모든 상자 글자 범위 검사: 넘침 없음. 전체 SVG 51개에 스크립트 없음.
- 공식 이미지 7개 원본 육안 검토 및 PNG 크기·SHA256 메타데이터 일치. 제품 화면과 설명 가정값 분리.
- 390px 프레임 6개에서 document clientWidth=scrollWidth=375 확인. 표·그림은 내부 스크롤 영역 제공.
- 기존 13강의 main section 본문 직렬화 동일, 기존 Markdown 전부 바이트 동일. 홈페이지 과정 카드 밖 바이트 동일.
- 장별 1~6강 번호, 전체 사이드바, 현재 장 펼침, 4장 5강→5장 1강 이동, 공식 화면 바로가기 포함.
