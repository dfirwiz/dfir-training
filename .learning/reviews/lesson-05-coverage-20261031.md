# 5강 원문 대응과 검토 기록

확인일은 2026년 10월 31일 UTC입니다. 대상은 인쇄 46~50쪽, PDF 48~52쪽입니다. 해당 범위의 전체 OCR과 다섯 페이지의 실제 이미지를 대조했습니다. 원문과 화면은 저장소에 포함하지 않습니다. 최신 main의 편집 기준, 진행 상태, 과정 목록, 생성 스크립트 및 상세 보강된 1·2·3강과 직전 4강을 확인했습니다.

이번 범위에는 직접 실행할 명령 옵션이나 코드가 없습니다. 특정 원본 실습 출력도 새로 만들지 않았습니다. 표는 개념 비교와 위치 대응을 돕고 본문 설명을 대체하지 않습니다. 주요 질문과 해설은 접힌 UI 없이 바로 표시합니다.

## 예시·계산과 판단의 경계

- 가상 데이터: 첫 범위 1000~1003, 다음 범위 1002~1005, 충돌 위치 1002·1003.
- 각각 4바이트이지만 서로 다른 스트림 위치는 1005 - 1000 + 1 = 6개. 겹침은 2바이트.
- 가정한 먼저 온 값 유지 결과 ABCDEF, 나중 온 값 선택 결과 ABXYEF. 실제 OS 정책이나 실행 결과가 아님을 명시.
- 두 세그먼트가 검토 대상이며 아직 응용에 전달되지 않은 데이터라는 전제를 명시. SYN·FIN과 양방향 번호 공간의 차이도 주의.
- 0x10 = 0001 0000 이진수 = 십진수 16. 숫자의 표현과 필드 의미를 구분.
- 주소는 문서용 192.0.2.10과 198.51.100.20 사용. 443만으로 TLS라 확정하지 않음.
- 값 충돌, 센서 해석, 실제 수신 처리, 응용 결과와 공격 성공을 구분. 도구나 무응답만으로 의도·실력·무해함을 단정하지 않음.
- 암호화된 데이터의 재조립과 평문 복호화는 구별. 패킷의 분석 가치와 추가 증거 필요성을 함께 설명.

## 현재성 확인

공식 RFC Editor의 안내와 정오표 절차, RFC 9293·768·791·792·8200·9000·2119·8174·9413, Suricata 8.0.1 공식 설정 문서, Wireshark의 오프로딩 문서를 조회했습니다. 확인 날짜와 각 근거 링크를 본문에 기록했습니다.

TCP 통합 명세는 2022년 변경이며 IPv6 대체 명세는 이미 2017년 발행되었음을 구분했습니다. RFC 9413은 Informational이며 개별 프로토콜의 의무 규칙을 대체하지 않습니다. Suricata 문서는 확인한 버전을 명시하고 최신판 전체 또는 모든 배포 환경을 검증했다고 주장하지 않습니다. 정오표도 신고와 검증을 구분합니다.

## 게시 전 검증

원문 학습 포인트와 모든 대응 절, 용어 정의, 예제 산술, 참고 링크와 표·SVG를 검토했습니다. 구조 검사에서는 홈페이지와 노트 5개, 로컬 링크·자산 219개, 새 노트의 목차 12절과 참고문헌 13개를 확인했습니다. 중복 ID와 누락 앵커가 없고 이전/다음 이동 및 공개 상태와 순차 진행 정보가 일치함을 검증했습니다. 기존 1~4강 본문과 생성 스크립트는 최신 main과 같으며, 기존 본문의 축약 없이 탐색 링크만 재생성합니다. 실제 브라우저 시각 검증은 기존 미리보기 인프라 제한으로 수행하지 못하므로 기존 반응형 스타일과 SVG 구조 검사로 범위를 제한합니다. 공개 페이지의 시각 검증 완료라고 보고하지 않습니다.

완료 범위는 인쇄 50쪽까지이며 다음 회차는 6강, 인쇄 51쪽부터입니다. 이번 실행에서 한 회차만 게시하며 전체 학습은 아직 진행 중입니다. 별도 워크북을 확보한다면 해당 연습은 추가 확인 대상으로 남습니다.
