## 상시 적용: Cobalt Strike 실제 화면과 설정 안내

2026년 11월 3일 사용자는 앞으로 별도 지시 없이 Cobalt Strike 화면과 설정 방법을 기본으로 포함하도록 명시했다. 이 규칙은 이후 작성·수정하는 모든 Cobalt Strike 관련 강의에 적용하며, 특정 장에 한정하지 않는다. 화면 보강 여부를 사용자에게 다시 묻거나 추가 요청을 기다리지 않는다.

- 관련 기능의 **실제 제품 화면**을 제공한다. 공개 공식 화면 또는 공개 사용이 허용된 실제 캡처를 사용하고, 비공개 교재 화면·원문·식별자는 게시하지 않는다. 개념도나 재구성한 화면을 실제 제품 캡처라고 부르지 않는다.
- **메뉴 경로 → 클릭 순서 → 입력 칸 → 예시값 → 실행·저장 버튼 → 결과 확인**을 화면과 함께 설명한다. 항목별 위치·의미·선택 이유·전제 조건을 밝히며 개념 요약이나 필드 이름 나열로 끝내지 않는다.
- 설정 완료 후 확인할 창·목록·로그·예상 상태와 오류 시 재확인할 항목을 연결한다. 등록·전달·저장·실행·세션 생성 등 서로 다른 성공 조건은 구별한다.
- 해당 강의와 장별 목차에서 **화면 실습으로 바로 가는 진입점**을 제공한다. 그림은 글자를 읽을 수 있는 크기로 표시하고 원본 확대·모바일 내부 스크롤·설정 단계 바로가기를 확인한다.
- 공식 원본의 예시값과 강의의 실습값을 구별한다. 제품 버전·메뉴 차이·확인일·출처를 표시하며, 실제 수행한 결과와 가상·미실행 예제를 명확히 나눈다.
- 필요한 실제 화면을 확보하지 못하면 미확보한 구간을 구체적으로 밝힌다. 확보된 실제 화면을 먼저 제공하고 부족한 구간의 설명표·개념도는 그 성격을 표시한다. 이를 실제 설정창이나 실행 결과 사진으로 대신 제시하지 않는다.
- 게시 전 실제 화면 표시·입력 설명 대응·단계별 링크·결과 확인 설명을 검토한다. 기존 상세 본문·다이어그램·복습과 즉시 해설 등 다른 작성 기준도 함께 유지한다.
