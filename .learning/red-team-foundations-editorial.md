# 레드팀 기초 과정 작성·게시 기준

공개 과정명은 **레드팀 기초: 공격 이해와 보안 검증**이다. 기존 두 과정의 디자인과 글꼴을 유지하며 독립적인 회차 번호를 사용한다.

- 본문: `content/red-team-foundations/*.md`
- 과정 메타데이터: `content/red-team-foundations/course.json`
- 빌드: `python3 scripts/build_red_team_foundations.py`
- 배포: `courses/red-team-foundations/`
- 전용 스타일과 SVG: `assets/red-team-foundations/`
- 진행 정보: `.learning/red-team-foundations-progress.json`

2026년 11월 2일 사용자는 채팅에서 검토한 첫 단원의 세 회차 전체를 새 과정으로 게시하도록 승인했다. 설명 순서·문단·비유·예제·표·복습 해설을 축약하지 않는다. 공개 과정명과 회차 표기, 내부 출처 표기를 웹용으로 조정한다. 비공개 자료의 파일명·식별자, 원문·화면·파일은 공개하지 않는다.

다이어그램은 원래 노드·분기·되돌아가는 관계를 보존한 SVG로 만든다. 비교표·코드·그림은 좁은 화면에서 내부 스크롤을 제공한다. 복습 해설은 접지 않고 바로 읽을 수 있게 한다. 공식 근거 링크와 확인일, 가상 예제·미실행 절차의 구분을 유지한다.

새 강의는 별도 지시가 있을 때 추가한다. 다른 과정의 진도나 자동화 설정은 변경하지 않는다.

## 두 번째 단원 요약 게시 예외 — 2026년 11월 2일

사용자는 두 번째 단원을 기존 설명 스타일로 작성하되 핵심만 요약해 사이트에 직접 게시하도록 명시적으로 요청했다. 이 단원은 4강 한 편으로 게시한다. 친근한 한국어, 구체적 상황과 비유, 판단 예시, 비교표, 즉시 읽는 복습 해설 및 공식 출처를 유지한다. 이 요약 예외는 두 번째 단원에만 적용하며 첫 단원 1~3강 본문은 유지한다.

## 세 번째 단원 상세 강의 게시 — 2026년 11월 2일

사용자는 두 번째 단원이 다른 대화에서 업데이트되었음을 알리고 세 번째 단원을 정상적으로 게시하도록 요청했다. 요약 예외를 확대하지 않고 5~8강 상세 설명으로 게시한다. PE·프로세스와 메모리·보안 문맥·코드 주입의 증거 해석·C# P/Invoke를 다룬다. 기존 1~4강의 본문과 다른 과정은 유지하며 과정 목차와 다음 강의 연결만 갱신한다. 5강의 합성 헤더 Python 검사만 실제 수행했으며 Windows와 C# 예제는 미실행으로 명시한다.

## 네 번째 단원 상세 강의 게시 — 2026년 11월 3일

사용자는 앞 단원의 작성·게시 흐름을 이어 4장을 요청했다. 9~13강으로 구성 요소·HTTP/DNS·SMB/TCP·페이로드와 로더·세션과 작업 기록을 상세히 설명한다. 기존 공개 과정명과 디자인을 유지하고 비공개 원문·화면·식별자는 공개하지 않는다. 개념도 10개와 복습·즉시 해설 40개를 독립 작성한다. 공식 현행 4.13 문서와 버전별 변경 이력을 대조한다. 13강의 가상 이벤트 처리는 실제 실행하고 제품·에이전트·Windows·네트워크 예제는 미실행으로 표시한다. 기존 1~8강 본문과 확인일·게시 날짜를 유지하고 과정 목차와 강의 이동을 갱신한다. 다음 단원은 추가 요청을 기다린다.

## 장별 메뉴와 강의 번호 — 2026년 11월 3일

사용자는 교재 제목을 중간 장 제목으로 추가하고 각 장 아래 강의를 1강부터 표시하도록 요청했다. 공개 장 제목은 Getting Started, Law & Compliance, Malware Essentials, Cobalt Strike Primer이며 1~4장에 각각 3·1·4·5개 강의를 배치한다. `course.json`의 `chapters`와 각 강의 `unit`·`lesson_number`를 표시 번호의 기준으로 사용한다. 기존 `id`와 파일 경로는 내부 식별자로 유지하고 강의 본문과 제목·날짜·예제는 수정하지 않는다. 사이드바·과정 전체 목차·홈 과정 카드·강의 헤더와 이전/다음 이동은 장별 번호를 사용한다. 현재 장을 기본으로 펼치고 다른 장은 사용자가 펼칠 수 있다. 새 장을 게시할 때도 교재 제목과 장별 번호를 메타데이터에 추가한다.

## 4장 실제 제품 화면과 설정 순서 보강 — 2026년 11월 3일

사용자는 기존 4장이 실제 화면과 구체적인 설정 위치를 충분히 설명하지 않는다고 지적했다. 4장 1~5강에 공개된 Fortra 공식 안내서의 실제 제품 화면 13개를 출처와 함께 추가하고 메뉴 경로·클릭 순서·입력 위치·설명용 값·저장 후 확인 지점을 보강한다. 비공개 교재 화면을 게시하지 않는 기존 원칙은 유지한다. 공식 삽화가 구버전 UI를 포함할 수 있음을 명시하고 실제 설치·C2·에이전트 실행을 수행한 것처럼 표현하지 않는다. 그림 자체는 변경하지 않으며 원본 확대 링크와 화면 바로가기를 제공한다. 기존 개념 설명·복습 해설·장별 메뉴·1~3장 본문은 유지한다.

## 3장 개념도 보강 — 2026년 11월 3일

사용자는 원본 교재를 참조해 3장 개념 이해를 돕는 다이어그램을 보충하도록 요청했다. 원본의 PE·프로세스·메모리·토큰·주입 계열·P/Invoke 범위를 현재 본문 및 Microsoft·MITRE 공식 설명과 대조하고, 기존 4개 강의에 독립 제작 SVG를 3개씩 추가한다. 원본 화면·원문을 공개하지 않는다. 기존 8개 그림과 모든 본문·표·코드·32개 복습 및 즉시 해설은 보존한다. 추가한 12개 그림에는 읽는 방향·비교 기준·가정·한계를 설명하는 문단과 대체 텍스트를 제공한다. 개념도·계산과 실제 Windows 실행 결과를 구별한다. 다른 장·메뉴와 다른 과정은 변경하지 않는다.
