자체 가상 주장·정수 범위 비교입니다. 실제 권한 상승이나 Dirty Pipe 재현 프로그램이 아닙니다.
Python 3 기본 라이브러리: python compare_boundaries.py cases.json
paths: 쓰기 가능 주장·높은 권한 소비자 주장·발동 연결 주장이 모두 참인지 비교합니다. 거짓이 하나면 false, 거짓 없이 미확인이 있으면 null, 모두 참이면 true입니다.
ranges: 읽기 주장, 시작의 페이지 경계 여부, 범위가 한 페이지와 선언한 파일 길이 안인지 비교합니다. 끝은 포함하지 않는 바이트 위치입니다. 16바이트 페이지는 설명용이며 실제 시스템 페이지 크기가 아닙니다.
실제 파일·메모리·운영체제·커널 버전을 조회하거나 쓰지 않습니다. 파이프·서비스·작업·레지스트리·계정·네트워크·취약점 코드를 실행하지 않습니다.
범위 조건 일치는 취약점 존재·악용 가능성·권한 상승 성공의 검증이 아닙니다. 모든 actual_*는 false, 사건 판단은 unresolved, 외부 동작은 0입니다. 종료2는 입력 오류입니다.
