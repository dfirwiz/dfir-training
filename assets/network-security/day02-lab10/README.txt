둘째 날9·10강 독립 가상 메타데이터 예제입니다. 실제 사건 로그·TLS 패킷·원본 워크북 자료가 아닙니다.
Python 표준 라이브러리만 사용합니다. 검증 환경 Python3.12.14.
python review_chain.py cases.json
python fingerprint_hello.py hello-fields.json
review_chain.py: 가상 Location의 절대 URL 변환/문자열 비교, 입력한 본문 길이 비교만 합니다. 시간·세션·행위·실제 침해 성공을 검증하지 않습니다.
fingerprint_hello.py: 직접 만든 선택 필드의 숫자 목록에서 JA3 형식 문자열과 MD5를 계산합니다. 실제 ClientHello 추출·TLS 협상·인증서 검증·프로그램 식별·조회가 아닙니다.
MD5는 기존 지문 방식의 표현을 설명하는 용도이며 보안 서명이나 충돌 저항을 보장하는 인증 수단이 아닙니다.
설명·이름·행위 보고를 바꿔도 직접 계산하지 않는 사실은 알 수 없습니다. 모든 사건 판정은 미확인입니다.
입력 파일을 읽고 출력만 합니다. 외부 요청/스캔/JARM/로그인/TLS 연결/복호화/CA 설치/키 수집/파일 실행/차단/메시지/구매는 하지 않습니다.
종료0은 계산 완료(비일치와 미확인 포함),오류2는 입력·지원 범위 오류입니다. 임의 사건 자료용 분석기나 인증서 검증기로 사용하지 않습니다.
