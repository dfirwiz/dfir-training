자체 가상 자격 증명 조사 기록의 종류와 연결 주장만 비교합니다. 실제 로그·암호·해시·티켓은 포함하지 않습니다.
Python 3 기본 라이브러리: python compare_evidence.py cases.json
이 연습에서 정한 다섯 기록 종류의 존재와 같은 계정·같은 대상·시간 순서의 주장만 대조합니다. 일반적인 자격 증명 탈취 탐지기나 인과 분석기가 아닙니다. 실제 사건에는 다른 증거 경로가 있을 수 있습니다.
종류가 모두 있어도 악성 여부·추출·동일 자료 재사용·실제 인증·권한·동작 성공·승인은 검증하지 않습니다. material_type_claim은 가상 분류 표지이며 원격 재사용 가능성을 계산하지 않습니다.
C7의 캐시 로그온 검증값과 인증 수락 기록이 함께 선언돼도 그 검증값을 원격 인증에 사용했다는 뜻이 아닙니다.
실제 프로세스·메모리·레지스트리·파일 비밀·네트워크를 조회하지 않고 어떤 자격 증명 도구도 실행하지 않습니다. 모든 actual_*는 false, 사건 판단 unresolved, 외부 동작0입니다. 종료2는 입력 오류입니다.
