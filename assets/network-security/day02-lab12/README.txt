둘째 날12강 독립 가상 이메일입니다. 실제 발송·수신·서버·사용자 자료가 아닙니다.
Python 표준 라이브러리만 사용합니다. 검증 환경 Python3.12.14.
python inspect_mail.py message.eml trace-policy.json
Received 세 필드와 UTC 변환,인접 시각 차이,명시한 경계 행과 예상 주소의 문자열 비교를 출력합니다.
trace-policy.json은 분석가가 넣은 가상 가정입니다. 서버 신뢰·수집 출처·서명·실제 접속·사람을 검증하는 인증 자료가 아닙니다.
Received에서 단순한 by 이름/[IPv4]/마지막 세미콜론 뒤 날짜만 읽는 고정 예제입니다. 모든 서버 문법·주석·IPv6·변칙 메시지 분석기가 아닙니다.
MIME 부분의 형식 이름만 나열합니다. HTML 렌더링·첨부 실행·외부 주소 조회·SMTP 연결·메일 발송·SPF/DKIM/DMARC 검증은 하지 않습니다.
smtp-session.txt는 별도 수기 작성한 가상 대화이며 .eml 파일을 그 대화에서 수집한 것이 아닙니다. 이 프로그램도 해당 대화를 분석하지 않습니다.
message.eml은 CRLF 원본 바이트를 보존합니다. 해시는 이 예제 파일의 동일성만 확인하며 진위나 발신자를 보증하지 않습니다.
종료0은 계산 완료(음수 시차·예상 주소 불일치 포함),오류2는 입력/지원 범위 오류입니다. 모든 사건 판정은 unresolved입니다.
