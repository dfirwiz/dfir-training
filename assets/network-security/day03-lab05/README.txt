자체 가상 연결·인증·읽기·로컬 복사 주장과 자체 참조 파일의 지문 비교입니다.
Python 3 기본 라이브러리: python compare_movement.py cases.json reference-note.txt
실제 읽는 파일은 두 입력 파일뿐입니다. 참조 텍스트의 길이와 SHA-256은 직접 계산하지만 원격 서버의 자료·로그·인증·읽기·복사·실행·승인·시각 인과는 검증하지 않습니다.
호스트·계정·객체 표지는 일치/불일치/미확인으로 비교합니다. 같은 이름·지문만으로 실제 사건의 출처나 원인을 증명하지 않습니다. 공백/대소문자 정규화·주소 임대·NAT·실제 파일 식별·시간 순서·암호화·압축·재조립을 구현한 모형이 아닙니다.
참조 파일은 민감하지 않은 자체 문장입니다. M3 후보 참은 가상 주장과 자체 참조 비교가 맞다는 뜻이며 실제 내부 이동/악성 수집/외부 반출이 아닙니다. 모든 actual_* false, 사건 unresolved, 외부 동작0. 종료2는 입력 오류입니다.
