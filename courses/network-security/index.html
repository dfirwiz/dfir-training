NETWORK SECURITY / COURSE 02

네트워크 보안 분석: 통신 원리부터 침해 조사까지

네트워크를 처음 배우는 독자를 위한 한국어 강의. 통신 구조와 프로토콜의 원리를 패킷 분석과 보안 조사에 연결합니다.

초보자를 위한 독립 과정업데이트 2026-11-02

통신의 원리에서 조사 판단까지

의심스러운 통신을 발견했을 때, 어느 기록을 확인하고 어디까지 결론을 내릴 수 있을까요? 이 과정에서는 상황과 문제에서 출발해 생활 속 비유, 실제 기술의 동작, 작은 예제, 조건을 바꾼 사례, 조사에서의 해석 순서로 배웁니다.

이전에 네트워크를 배웠다고 가정하지 않습니다. 용어를 처음 사용할 때 의미를 설명하고, 패킷에서 관측한 사실과 그 사실이 지지하는 가설, 추가 증거가 필요한 결론을 구분합니다.

현재 공개된 강의: 1~6강

네트워크 구조부터 순서대로 연재합니다. 각 강의에는 본문 설명, 필요한 표와 그림, 최신 보충의 근거, 바로 읽을 수 있는 복습 해설을 포함합니다.

강의 목차

LESSON 01 / 공개

네트워크 구조: 통신이 지나가는 길과 증거가 남는 위치

라우터·보안 구역·스위치·TAP과 미러링·방화벽·제로 트러스트를 조사에 연결합니다. 그림 4개와 복습 질문·해설 10개를 함께 읽습니다.

1강 읽기 ↗LESSON 02 / 공개

트래픽 수집과 분석 — 요약 기록에서 패킷 증거까지

세 종류의 수집 자료, 플로와 샘플링, 메타데이터, 저장 용량, 표시 필터와 요청·응답을 연결합니다. 그림 3개, 명령·필터 예제, 복습 12문항과 해설을 함께 읽습니다.

2강 읽기 ↗LESSON 03 / 공개

DNS의 동작 원리 — 이름에서 주소로, 응답에서 증거로

조회 경로와 캐시, 주소·별칭·메일·서비스 레코드, 질문·응답 짝짓기와 관측 한계를 배웁니다. 그림 4개, 자체 패킷 연습, 복습 14문항과 해설을 포함합니다.

3강 읽기 ↗LESSON 04 / 공개

DNS 분석과 공격 징후 — 조회 기록에서 조사 판단까지

로그 수집 위치, 도메인 보강, 비인가 DNS, 터널링, 유사 문자와 암호화 DNS를 조사 판단에 연결합니다. 그림 5개, 종합 가상 사례, 복습 18문항과 해설을 포함합니다.

4강 읽기 ↗LESSON 05 / 공개

DNS 분석 실습 — 질문·응답에서 조사 기록까지

자체 PCAP과 보조 로그를 내려받아 질문·응답, 재시도, 빈 답, 비인가 경로와 TCP 전환을 분석합니다. 그림 4개, 실습 해설, 복습 16문항을 포함합니다.

5강 읽기 ↗LESSON 06 / 공개

HTTP의 동작 원리 — 웹 요청과 응답 읽기

URL, 메서드, 헤더·상태, 쿠키·캐시·압축을 이해하고 HTTP/2·3의 스트림과 관측 한계로 이어갑니다. 그림 5개, 자체 요청·응답 풀이, 복습 20문항과 해설을 포함합니다.

예제와 분석 결과의 구분

1~4강의 주소·구성·조사 사례는 설명을 위해 만든 문서용 자체 예제입니다. 실제 네트워크 수집본의 분석 결과가 아닙니다. 5강은 자체 합성 PCAP과 가상 보조 기록을 제공하며, 파일 해석에서 확인한 결과와 가상 맥락·실행하지 않은 절차를 구분합니다. 6강의 HTTP 메시지는 자체 가상 예제이며 로컬 계산 결과와 실제 통신 분석을 구별합니다.
