블루팀 필수 지식: 보안 운영과 분석

블루팀이 갖춰야 할 보안 운영과 분석의 필수 지식. 첫째 날부터 네트워크, 단말·로그·파일, 조사, 탐지 개선과 자동화까지 날짜별로 배웁니다.

보안 운영·분석을 시작하는 독자를 위한 과정업데이트 2026-11-06

블루팀이 갖춰야 할 지식을 처음부터

경보가 울렸을 때 무엇부터 확인하고, 어떤 근거로 판단하며, 누구와 협업해야 할까요? 블루팀은 조직의 시스템을 지키는 사람들입니다. 이 과정은 보안 운영의 역할과 흐름부터 네트워크·단말·로그·파일의 원리, 조사와 탐지 개선까지 차근차근 연결합니다.

처음부터 용어를 알고 있다고 가정하지 않습니다. 구체적인 상황과 필요성에서 출발해 비유, 실제 동작, 작은 예제, 조건을 바꾼 사례, 조사 결과의 해석 순서로 배웁니다. 관측한 사실과 가설, 추가 증거가 필요한 결론을 구분합니다.

현재 공개: 30개 강의 · 첫째 날 24개

첫째 날부터 날짜별로 순서대로 상세 강의를 업데이트합니다. 각 날짜 아래에서 공개된 강의를 읽을 수 있습니다. 다음 업데이트는 첫째 날 25강, ‘첫째 날 종합 복습’부터입니다.

각 ‘날’은 학습 주제를 묶는 단위입니다. 하루에 전부 읽어야 하는 분량을 뜻하지 않습니다. 강의마다 필요한 배경·예제·예외·복습 해설을 충분히 담고, 내용이 길면 회차를 더 나눕니다.

첫째 날 사례 모듈은21강 Mirai,22강 Colonial Pipeline,23강 Conti,24강 SolarWinds로 세분화합니다. 기존 공개 번호·ID·URL·본문은 유지하며 복습/종합실습은25/26강입니다.

강의는 독립적인 설명·예제·도식으로 작성합니다. 본문에서 가상 사례, 자체 실습 자료, 실제로 확인한 결과와 실행하지 않은 절차를 구분합니다. 기존 둘째 날 1~4강의 사례는 문서용 자체 예제입니다. 5강은 자체 합성 PCAP과 가상 보조 기록을 제공하며, 6강의 HTTP 메시지는 자체 가상 예제입니다.

각 회차에는 복습 질문과 바로 읽을 수 있는 해설을 포함합니다. 최신 기술 보충에는 적용 조건·확인 날짜·근거 링크를 붙입니다.
