공통 시나리오

가상 회사의 회계팀 Windows 단말 WS-FIN-07에서 외부 연결 경보가 발생합니다. 1강에서는 연결을 만든 프로세스를 찾고, 이후 강의에서는 실행 출처와 정상 소프트웨어 여부, 영향을 받은 단말 범위를 좁힙니다. 마지막에는 조사 결과를 인계 보고서로 작성합니다.

레드팀 기초의 목표·TTP·증거와 4장 Cobalt Strike Primer에서 배운 개념을 가져옵니다. 각 강의는 원리 → 화면 또는 로그 읽기 → 시나리오 실습 → 즉시 해설 순서입니다. 첫 실습에는 브라우저나 스프레드시트만 있으면 됩니다.
