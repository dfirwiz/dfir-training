`.learning/red-team-foundations-editorial.md`를 읽고 적용한다.

## 사용자 상시 지시: Cobalt Strike 화면과 설정 방법

Cobalt Strike를 다루는 강의에는 별도 요청이나 재확인 없이 다음을 기본으로 포함한다.

1. 공개 사용이 허용된 **실제 Cobalt Strike 화면**과 출처·버전 주의.
2. **메뉴 경로 → 클릭 순서 → 입력 위치 → 예시값과 이유 → 저장·실행 버튼 → 결과 확인**의 구체적인 설명.
3. 설정 후 확인할 화면·목록·로그·예상 상태 및 오류 시 재확인할 지점.
4. 장별 목차와 강의 상단의 설정 실습 바로가기, 읽기 쉬운 이미지 크기·원본 확대·모바일 표시.

공식 화면의 예시값과 실습 가정값, 실제 수행 결과와 가상·미실행 예제를 구별한다.
실제 사진이 없는 구간은 구체적으로 표시하고 설명표·개념도를 실제 캡처처럼 제시하지 않는다.
비공개 교재 원문·화면·파일 식별자는 공개하지 않는다.
상세 본문·다이어그램·복습과 즉시 해설 등 기존 작성 기준을 함께 유지한다.
